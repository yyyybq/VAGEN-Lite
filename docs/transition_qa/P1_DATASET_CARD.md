# P1 数据集卡片：InteriorGS 转移题（2026-10-20 版）

论文"数据集"一节的底稿。数字来自 `exps/transition_qa_20261019b`（`stats.json`、`probe_stats.json`、`shortcuts.md`）、`P1_STATS.md`、`DIAG3_PROBE.md`；字段和规则见 `DATA_CONTRACT.md`，题型见 `P1_QTYPES.md`。2026-10-19 版（`exps/transition_qa_20261019`）有三处只看文字就能答的捷径，这一版修掉了（第 7 节）。

> 名字提醒：P1 是这个数据池（转移题）；v10_p1 / v10_p2 是 RL 修正包，和它无关。

## 1. 一句话

**P1 是一批围绕导航任务的多选题。** 给一张（逆向题两张）室内 3D 高斯渲染图，问三种问题：
- 当前画面里的空间关系（**状态题**）；
- 做一个相机动作之后会怎样（**前向题**，不给动作后的画面）；
- 两张图之间相机做了什么动作（**逆向题**）。

**答案全部由环境自己的几何判定函数算出**，和导航环境的成功判定一致，不靠人工标注，也不靠模型生成。**只看题目文字答不出**：答案在题干能透露的每一格里都配平了，选项的构造也不泄露答案（第 5 节）。

用途：给"看图找位置"的导航策略做辅助 SFT 数据（矩阵 D 组），并作为检查模型空间理解的探针。

## 3. 来源

- **任务和轨迹**：InteriorGS v10 生成器的正式题。用第十一轮 SFT 数据的 11,095 条最短路径轨迹（train 9,802、val 1,293），842 个场景。
  - 每条轨迹的每个不同的帧都拿来出题，共 38,638 个状态。
  - 这里含 v2 验证集新增的 15 道遮挡题：它们没有 SFT 轨迹，按最短路径另渲染了 58 张帧。
- **图像**：256 × 256，判据用的同一个相机（`canonical_camera`）。
  - 另有 7,528 张"目标区域内部的成功状态"：终点附近挪 ±10 cm、转 ±6° 仍成功的位姿，只用于 `goal_now` 的"是"。
- **答案**：环境的成功判定（标准判据 + 可见规则 face_visible_v3 + 左右 45°），以及各族判据里的同一个量。
  - 这些量是：地面投影距离、投影横坐标差、被挡比例、画面内比例、高度占比。
  - 逆向题的动作来自轨迹记录，用动作函数复核前后位姿。
- **一致性**：全部 11,110 条轨迹的终点都成功、终点前都不成功；在 42 个真实状态上，成功判定和环境的函数逐位相同（集成测试）。
- **人工核对**（用户，2026-10-20）：30 道题，28 道判对，2 道判错。复查后只有 1 道是真错（第 7 节第 1 条）；另一道（第 20 题，逆向题）两帧的位姿差正好是后退 0.300 m，答案没错，判错是因为核对页同时显示了任务原文。

## 5. 答案分布和"只看文字"

- **字母**：每个题类、每个文件，正确字母和均匀分布最多差 2.4 个百分点（训练、测试；探针 2.5；验收线 5）。
  - 选项顺序无含义的题类（哪个更近、遮挡、视野、动作）字母完全均匀；
  - 是非题 Yes：`goal_now` 47.6%、`goal_after` 49.7%。
- **答案在题干格里配平**：是非、左右、遮挡、视野四类，在同一个任务族、同一个动作 × 次数里各答案一样多（视野题最多 2 倍）。题干里除了物体名，能透露的只有任务原文（即任务族）和动作，所以光凭题干猜不出。
- **逆向题的选项是 2 × 2**：{真实动作，配对动作} × {真实次数，相邻次数}，每个动作、每个次数都出现两次；4 种答案在每一组选项里配平。
- **距离、高度的选项窗口在构建时分配**：同一组 4 个选项里 A–D 一样多。
- **复查**（`python -m data_gen.transition_qa.shortcuts`，只用题目文字的规则，规则在训练集上学，用到测试集）：

| 题类 | 最强的文字规则（测试集） | 随机猜 | 2026-10-19 版 |
| --- | --- | --- | --- |
| `action_between` | 26.3% | 25% | 100% |
| `goal_after` | 51.2% | 50% | 71.9% |
| `goal_now` | 52.4% | 50% | 65.3% |
| `both_in_view_after` | 27.3% | 25% | 39.2% |
| `distance_bin_now` / `_after` | 26.3% / 25.5% | 25% | 44.0% / 36.5% |
| `height_bin_now` / `_after` | 25.9% / 24.1% | 25% | 35.2% / 34.4% |
| 其余题类 | 最高 `left_right_after` 55.4%（139 道，随机 50%；标准误约 ±4.2 个百分点）、`both_in_view_now` 28.6%（252 道，随机 25%） | | |

  原版 7B 不看图的准确率（同样只给题干和选项）见 `P1_STATS.md` 第 7 节和本文第 6 节。
- **答案值**（训练集）：
  - 距离多在 1.5–3.0 米；高度占比多在 0.2–0.4；
  - 视野：`both_in_view_after` 只有 B 954 / 只有 A 917 / 都不在 869 / 都在 574；

## 6. 探针基线（诊断 3，1,041 道）

| 模型 | 准确率 | 状态 / 前向 / 逆向 | 格式不合规 |
| --- | --- | --- | --- |
| 随机猜（按题数加权） | 40.1% | | |
| 原始 Qwen2.5-VL-7B，不看图（只给题干和选项） | 34.3% | 36.3 / 33.2 / 25.0 | 35.8%（先推理；7.4% 拒答） |
| 原始 Qwen2.5-VL-7B | 41.9% | 46.1 / 39.1 / 27.5 | 8.5%（先推理再答） |
| 第十一轮 SFT（只练动作）10 个 epoch | 41.6%–43.2% | | 34%–53%（写成 `(B)`） |
| 修正包 RL P-S0 / P-D 各 6 个检查点 | 40.5%–42.3% | | 47%–56% |

- 标准误约 ±1.5 个百分点：所有模型都只比随机猜高 0.4–3.1 个百分点，现有的动作训练不改变回答这些题的能力。
- 不看图低于随机猜：它在 goal 题上永远答 No，遮挡题总答"没有被挡"，另有一些回答是"看不到图没法答"。测试集上同样（35.5% 对随机 38.5%），没有哪个题类明显高于随机猜（`P1_STATS.md` 第 7 节）。
- 所有模型在 goal 题上几乎总答 No：答案是 Yes 时答对 0%–19%（每类 100 道）。
- 训练后的模型在遮挡题上低于随机：平衡准确率 `occluded_now` 19%–36%（原始 7B 42%），随机 33%。
- 逆向题 22.5%–37.5%（随机 25%）：2026-10-19 版里原始 7B 的 77.5% 来自选项文字的捷径。
- 详见 `DIAG3_PROBE.md`。

## 7. 已知问题和局限

1. **遮挡物按实心的包围盒算。** 环境的遮挡判据和遮挡题用同一个函数，都把遮挡物当成实心长方体。内部空的、镂空的或不规则的物体（敞开的衣柜、人、显示器、画架、枯枝等），框挡住了目标，画面里却看得见目标，这时答案和画面不符。人工核对的第 18 题就是这种情况（衣柜）。题库里遮挡物是衣柜的占遮挡候选题的 11.8%，人占 5.8%，细或不规则的物体合计约 15%。这是主线判据的问题，题库没改。
2. **goal 题占比高**：`goal_now` 占状态题 68.6%，两类 goal 题合计占训练集 51.9%。
3. **遮挡题少**：训练集 679 道（`occluded_now` 267 + `occluded_after` 412）；测试集没有（全部进了探针集）；探针集答案不均（`occluded_now` 完全 46 / 部分 24 / 没有 7），总答"完全"能得 59.7%，所以这两类用各答案准确率的平均（平衡准确率）比较。
4. **左右前向题几乎从不翻转**：转身不改变前方两物体的左右顺序，`left_right_after` 的答案基本等于现在的答案。
5. **动作来自最短路径**，不是随机动作；分布偏后退和转身。
6. **2026-10-19 版的三处捷径已修**（`DIAG3_PROBE.md`）：逆向题只看选项 100% 可解；探针集遮挡、视野题的选项顺序泄露答案；距离、高度的选项窗口泄露字母。另修了这一版复查时新发现的第四处：只凭题干的任务和动作，goal 题能答对 65%–72%。

