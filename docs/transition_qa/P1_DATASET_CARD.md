# P1 数据集卡片：InteriorGS 转移题（2026-10-19 版）

论文"数据集"一节的底稿。数字来自 `exps/transition_qa_20261019`（`stats.json`、`probe_stats.json`）、`P1_STATS.md`、`DIAG3_PROBE.md`；字段和规则见 `DATA_CONTRACT.md`，题型见 `P1_QTYPES.md`。

> 名字提醒：P1 是这个数据池（转移题）；v10_p1 / v10_p2 是 RL 修正包，和它无关。

## 1. 一句话

**P1 是一批围绕导航任务的多选题。** 给一张（逆向题两张）室内 3D 高斯渲染图，问三种问题：
- 当前画面里的空间关系（**状态题**）；
- 做一个相机动作之后会怎样（**前向题**，不给动作后的画面）；
- 两张图之间相机做了什么动作（**逆向题**）。

**答案全部由环境自己的几何判定函数算出**，和导航环境的成功判定一致，不靠人工标注，也不靠模型生成。

用途：给"看图找位置"的导航策略做辅助 SFT 数据（矩阵 D 组），并作为检查模型空间理解的探针。

## 3. 来源

- **任务和轨迹**：InteriorGS v10 生成器的正式题。用第十一轮 SFT 数据的 11,095 条最短路径轨迹（train 9,802、val 1,293），842 个场景。
  - 每条轨迹的每个不同的帧都拿来出题，共 38,638 个状态。
  - 这里含 v2 验证集新增的 15 道遮挡题：它们没有 SFT 轨迹，按最短路径另渲染了 58 张帧。
- **图像**：256 × 256，判据用的同一个相机（`canonical_camera`）。
  - 另有 7,528 张"目标区域内部的成功状态"：终点附近挪 ±10 cm、转 ±6° 仍成功的位姿，只用于 `goal_now` 的"是"。
- **答案**：环境的成功判定（标准判据 + 可见规则 face_visible_v3 + 左右 45°），以及各族判据里的同一个量。
  - 这些量是：地面投影距离、投影横坐标差、被挡比例、画面内比例、高度占比。
  - 逆向题的动作来自轨迹记录，用动作函数复核前后位姿。
- **一致性**：全部 11,110 条轨迹的终点都成功、终点前都不成功；在 42 个真实状态上，成功判定和环境的函数逐位相同（集成测试）。

## 4. 过滤：没出的题和原因

**候选阶段。** 38,638 个状态出了 254,085 道候选题，大类分布是：

| 大类 | 候选题 |
| --- | --- |
| 状态题 | 54,860 |
| 前向题 | 171,697 |
| 逆向题 | 27,528 |

没出题的判定共 560,498 次。一个状态的一个题类算一次；前向题按每个候选动作算，所以次数比状态多。原因分布：

| 原因 | 次数 | 含义 |
| --- | --- | --- |
| `not_visible_now` | 190,383 | 前向题：被问物体在当前画面里看不清（face_visible_v3） |
| `near_boundary` | 119,839 | 测得的量离判定阈值太近（左右 < 20 px；距离差 < 5%；离选项 > 0.15 m / 0.03；遮挡比例在两档之间；视野在 0.30–0.95） |
| `blocked_move` | 76,203 | 前向题的候选动作被碰撞规则挡住 |
| `out_of_frame` | 50,279 | 左右前向题：动作后物体出画 |
| `cut_off_vertically` | 41,958 | 高度题：物体上下不完整 |
| `near_boundary_yes` / `_no` | 29,365 / 2,888 | goal 题：位姿挪 ±5 cm、转 ±3° 结论会变（终点大多贴着成功边界） |
| `behind_camera` | 21,009 | 物体在相机后方 |
| `not_visible` | 11,410 | 状态题：被问物体看不清 |
| `beyond_45deg` | 9,091 | 左右题：两物体连线和相机左右轴夹角 > 45° |
| 遮挡题的几种 | 7,690 | 目标出画 / 看不清 / 在相机后方，遮挡物不在视野或看不清 |

## 5. 答案分布

- **字母**：每个题类、每个文件，正确字母和均匀分布最多差 2.9 个百分点（训练、测试；验收线 5）。
  - 选项顺序无含义的题类（哪个更近、遮挡、视野、动作）字母完全均匀；
  - 是非题 Yes 47.6% / No 52.4%；
  - 四选一的距离、高度题 A/B/C 各 25.6%、D 23.3%。
- **答案值**（训练集）：
  - 距离多在 1.5–3.0 米；
  - 高度占比多在 0.2–0.4；
  - 视野四种结果各约四分之一；
  - 遮挡完全 / 部分 / 没有：`occluded_now` 93 / 81 / 93，`occluded_after` 197 / 208 / 172；
  - 动作以后退、转身、1–2 步为多（`move_backward` × 1 最多，1,616 道）。
- 各题类的完整分布在 `P1_STATS.md` 第 3 节，前向题"没变化 / 答案翻转"的比例在第 4 节。

## 6. 探针基线（诊断 3，600 道）

| 模型 | 准确率 | 状态 / 前向 / 逆向 | 格式不合规 |
| --- | --- | --- | --- |
| 随机猜（按题数加权） | 36.1% | | |
| 原始 Qwen2.5-VL-7B | 45.8% | 49.3 / 37.9 / 77.5 | 15.8%（先推理再答） |
| 第十一轮 SFT（只练动作）10 个 epoch | 45.0%–48.5% | | 48%–73%（写成 `(B)`） |
| 修正包 RL P-S0 / P-D 各 6 个检查点 | 42.3%–45.0% | | 65%–80% |

- 现有动作训练基本不改变回答这些题的能力。
- 所有模型在 goal 题上几乎总答 No：答案是 Yes 时答对 0%–20%。
- 训练后的模型在 `occluded_now` 上低于随机，因为多答"没有被挡"。
- 详见 `DIAG3_PROBE.md`。

## 7. 已知问题和局限

1. **逆向题只看选项文字就能答对**（2026-10-19 发现，没改，等用户定）。
   - 干扰项的构造使正确选项是唯一一个"动作出现两次、次数最常见"的选项。
   - 训练集 13,515 道、测试集 905 道、探针 40 道全部可解。
   - 改法：选项改成 2 动作 × 2 次数。
2. **探针集的遮挡、视野题从选项顺序能猜出答案**：探针步骤漏了打乱，56%–61% 对随机 25% / 33%。训练集、测试集没有这个问题。
3. **距离、高度题的选项窗口泄露答案位置**：只看最小选项能在测试集猜对 34%–44%（随机 25%）。
4. **goal 题占比高**：`goal_now` 占状态题 70.9%，两类 goal 题合计占训练集 50.6%。
5. **遮挡题少**：训练集 844 道（`occluded_now` 267 + `occluded_after` 577）；探针的 `occluded_now` 答案不均（完全 16 / 部分 17 / 没有 7）。
6. **左右前向题几乎从不翻转**：转身不改变前方两物体的左右顺序，`left_right_after` 的答案基本等于现在的答案。
7. **动作来自最短路径**，不是随机动作；分布偏后退和转身。
8. **人工核对还没有结果**：30 道核对页已做好（`exps/transition_qa_20261019/review/p1_review.html`），通过率待用户核完后填。

第 1–3 条用 `python -m data_gen.transition_qa.shortcuts --out <题库>` 可以复查，改好后所有规则都应回到随机猜的水平。
