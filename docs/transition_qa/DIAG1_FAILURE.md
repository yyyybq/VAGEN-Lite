# 诊断 1：第十二轮复现对的失败拆解（2026-10-19）

第十二轮的复现对：从第十一轮正式 SFT 第 9 个 epoch 起步的 P-S0 / P-D 一对（`interiorgs_v10_train_r12a_20261019`），也就是矩阵的 C0 组。本文按任务族拆它的评测结果。只读主线的结果文件，没有改主线任何东西，没有用 GPU。

## 结论

1. **最常见的失败仍是"用完步数时只差一个条件"。**
   - 验证集上，P-S0、P-D 第 300 次更新各有 35.4% / 33.2% 的题是这样结束的；起点 SFT 第 9 个 epoch 是 32.2%（都是占 413 道的比例）。
   - 评测集上分别是 41.8% / 37.0%，起点 38.0%（占 292 道）。
2. **RL 把一部分"差两个以上条件"的失败变成了成功或"只差一个"，没有减少"只差一个"。**
   - 验证集上，"用完步数·其他"从 26.9%（SFT e9）降到 19.4%（P-S0 300）/ 21.3%（P-D 300）。
   - 成功从 40.9% 升到 45.0% / 45.3%。
3. **"只差一个条件"的失败里，约 53%–65% 差的是"关系"组。**
   - 关系组是题目要求的空间关系：距离、等距、左右、被挡、画面占比等。
   - 验证集上 SFT e9 53%（133 道里 70 道）、P-S0 300 57%、P-D 300 57%；评测集上 61% / 63% / 60%。
   - 主线说的"约三分之二"和评测集的数接近，验证集低一些。
   - 投影族和视野族例外：它们差的几乎都是"画面"或"看清楚"组。投影族 SFT e9 在验证集只差一个的 29 道里只有 3 道差关系；视野族是 0。
4. **画面一片、格式错误几乎不出现。** 每个检查点 0–2 道（≤ 0.5%）：P-S0 早期是连续读不出动作，P-D 是画面几乎一片。
5. **按任务族**：
   - 遮挡族"只差一个"最多：验证集 P-S0 300 有 71.1%（38 道里 27 道），几乎都差"被挡"这个关系条件。
   - 等距族成功最少：14.7%–20%。
   - 绝对距离族和画面占比族成功最多：约 60%。

## 术语

- **门 / 条件**：成功判据里的一项条件，全部通过才算成功。
- **三组条件**，按主线第十二轮的分法（`interiorgs_v10_r12_20261019/scripts/dense_check_r12.py` 的 `GROUP`，本文另把 `target_in_front` 归入"画面"）：
  - ①**画面**：目标在相机前方、在画面里、够大；
  - ②**看清楚**：目标或参照物至少有一个面清楚可见；
  - ③**关系**：题目要求的空间关系成立。
- **每道题一个结论**（`eval/diagnostics/failure_breakdown.py`）：
  - **成功**；
  - **用完步数·只差一个**：12 个动作用完，最好的那个回合只差一个条件；
  - **用完步数·其他**：始终至少差两个；
  - **画面一片或格式错误**：没用完步数就结束了，按环境记下的原因分（画面几乎一片 `low_info`、连续三次读不出动作 `consecutive_invalid`、其他）。
  - "到过又走偏"在现行规则下不会发生（每个动作后都检查成功，满足就结束），各检查点都是 0，表里不列。

- **评测集**：第十二轮 v2。
  - 验证集 413 道 = 第十一轮 val400 的 398 道 + 15 道遮挡题；
  - 评测集 292 道 = 279 + 13。
- **RL 检查点**：`interiorgs_v10_r12_20261019/eval_{val,test}_v2/p1{s0,d}_{050..300}/results.jsonl`，第十二轮训练链自己的评测。
- **起点 SFT 第 9 个 epoch**：v2 题集上没有整体跑过，这里拼起来：
  - 第十一轮 `eval_val400` / `eval_test` 的结果（398 / 279 道），加上第十二轮 `eval_{val,test}_v2_oa` 里新增遮挡题的结果（15 / 13 道）；
