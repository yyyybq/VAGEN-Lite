## 要你定的三件事

1. **"同号"怎么算**。定稿要求"S0、D 两个 RL 的差同号"；现在每组有 2 个种子 × 2 侧 = 4 个 RL。
   - (a)（推荐）两个种子的差同号。每个种子的差是 S0、V4 两侧的平均。理由：决定 80 规定差别按种子配对算，种子是重复。两侧照样分开报。代价：比 (b) 宽，一侧方向相反时也可能判"有差异"。
   - (b) 四个配对的差全部同号。代价：最严；只要有一个配对反过来，就判不出"有差异"。
   - (c) 只看合起来的检验和门槛，不要求同号。代价：最宽，和决定 80 的"按种子配对"不一致。
2. **被停止线停下的 RL 用哪个检查点**。定稿用第 300 次。Qwen3 C0 种子 20261019 的 S0 在第 150 次被 10% 线停下，没有第 300 次。
   - (a)（推荐）用它最后一个检查点，标明停在第几次；"稳不稳"另作一项结果报告（决定 80）。代价：停下前的检查点可能已经开始走样，会拉低那一侧。
   - (b) 这个种子的这一侧不进比较，只用另一侧。代价：这个种子只剩一个配对，那一侧的种子数也少了一个。
3. **B′ 的 P2f 什么时候加**（不影响 D − C、D − C0，只影响 B′）。决定 75 说"先全用，格式不稳再加"。
   - (a)（推荐）B′ 任何一个 RL 被 10% 线停下就算"不稳"，由你定加多少，再重训 B′ 的 SFT。
   - (b) 不预先规定，看结果再说。

## 3. 指标

### 3.1 主指标：动作成功率（总）

| 项 | 规定 |
| --- | --- |
| 题集 | `eval_test_v2_screened` 292 道（只记录、不挑模型）；`eval_val_v2_screened` 382 道同样报告，作参考 |
| 指标 | 第 300 次检查点的成功率；4 个 RL 分别报，另报每个种子的两侧合起来、四个合起来（4 × 292 = 1,168 个"题 × RL"） |
| 比较 | D − C（主）、D − C0（次）；同一种子、同一侧配对，逐题配对 |
| 检验 | 符号检验（只看只有一方成功的题，双侧精确二项检验），α = 0.05；95% 置信区间按题做 2,000 次自助法 |
| 判定"有差异" | 四个合起来 p < 0.05，**且**差 ≥ 5 个百分点，**且**同号（按第 1 件） |
| 能测出的最小差 | 四个合起来约 3.4–4.5 个百分点（80% 把握，α = 0.05）；一个种子的两侧合起来约 4.8–6.3；单个 RL 约 6.8–9.0 |

- 最小差 ≈ 2.8 × √(不一致率 / 题数)。不一致率按 17%–30% 估：
  - 17%–22% 是第十二轮同一起点的两个模型；
  - 22.6% 是主线 Qwen3 报告里 V4 对 S0（三个种子合计 2,115 个"题 × 种子"里 477 个结果不同）；
  - D 和 C 的 SFT 不同，不一致率可能更高，按 30% 算是上限。
- 四个 RL 用的是同一批题，不完全独立，所以合起来的最小差偏乐观。5 个百分点的门槛仍比它大。
- **C0 在新测试集上：待补。**
  - 留下的 233 道和验证集 382 道，从主线已有的逐题结果取；
  - 补进来的 59 道要用 Qwen3 的运行时补跑，每个检查点一个单卡推理任务。

## 4. 假设和读法（不变）

- **H1（主）**：D 的动作成功率高于 C（3.1）。
- **H2**：D 在四类探针题上，尤其是"答案是 Yes 时"，准确率高于 C、C0（3.3）。
- **H3**：D 的"只差一个"失败里差"关系"的比例低于 C、C0（3.4）。
- 读法：
  - H2 成立而 H1 不成立：学会了回答转移题，但没有用到动作上。
  - H1 成立而 H3 不成立：提高来自别处，不是关系判断。
  - 三者都不成立：P1 这种形式没用（在这批题和这个训练量下）。

## 5. 报告格式

- 每个指标一张表：C0、C、D 的值；D − C、D − C0 的差，95% 置信区间、p 值。
- 先按种子、按侧分开报，再按种子合两侧，最后四个合起来。
- "稳不稳"单独一张表：每个 RL 有没有被停止线停下、停在第几次、停下的原因（决定 80）。
- 主指标的 p 值不校正；按族的结果用 Holm 校正；其余是次要指标，不校正，但写明一共比较了几次。
- 一律写清"多少道题里多少道"。

## 6. 不做的事（不变）

- 不按评测集挑检查点、挑题、挑族之后再下结论。
- 不用训练时的验证损失代替成功率下结论。
- 不把 E 组、D_noP0 组、B′ 组混进 D 的比较；它们各自单独报告。
