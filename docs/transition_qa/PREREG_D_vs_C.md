## 1. 比较的对象

| 组 | SFT 数据 | 起点 | RL |
| --- | --- | --- | --- |
| C0 | P2（主线，第十一轮正式 SFT） | 第 9 个 epoch（第十一轮按 val400 挑） | 第十二轮的复现对 P-S0 / P-D（`interiorgs_v10_train_r12a_20261019`） |
| C | P0 + P2 | 10 个 epoch 里按 eval_val_v2 挑 | 一对，设置和 C0 完全相同 |
| D | P0 + P1 + P2 | 同上 | 同上 |

- 三组的 RL 都是同一个标准、同一批后备题、同一个种子（20261019）、300 次更新；每组的 S0 和 D 两个 RL 当作这一组的**两次重复**。
- 每组只有一个种子。S0 和 D 的差别还混着奖励的差别，所以"两次重复"是近似的，结论要求两次方向一致。
- **主比较是 D − C**：两组只差 P1。**D − C0** 是次要比较，因为 C 和 C0 除了 P0 还差在 SFT 重训的随机性和挑 epoch 的题集。

## 2. 用哪个检查点

- **RL**：第 300 次更新的检查点（主）。不按评测集挑检查点，避免挑出偶然高的那个。
  - 第十二轮里同一个 RL 相邻两个检查点（第 250 和 300 次）就有 12%–13% 的题结果不同，挑最好的会系统性高估。
  - 按验证集挑的最好检查点只作探索性报告。
- **SFT**：每组按 eval_val_v2 挑出的那个 epoch（训练链的规则）。SFT 阶段的比较是次要的。

## 3. 指标

### 3.1 主指标：动作成功率（总）

| 项 | 规定 |
| --- | --- |
| 题集 | 第十二轮 v2 **评测集** `eval_test_v2`，292 道（只记录、不挑模型）；验证集 413 道同样报告，作参考 |
| 指标 | 第 300 次检查点的成功率；S0、D 两个 RL 分别报，另报合起来（2 × 292 = 584 个"题 × RL"） |
| 比较 | D − C（主）、D − C0（次）；逐题配对 |
| 检验 | 符号检验（只看只有一方成功的题，双侧精确二项检验），α = 0.05；95% 置信区间按题做 2,000 次自助法 |
| 判定"有差异" | 合起来 p < 0.05，**且**差 ≥ 5 个百分点，**且** S0、D 两个 RL 的差同号 |
| 能测出的最小差 | 约 4.7–4.9 个百分点（合起来，80% 把握，α = 0.05）；单个 RL 约 6.7–6.9 个百分点 |

- 最小差按第十二轮实测的逐题不一致率算：同一起点的两个模型约 17%–22% 的题结果不同（评测集 SFT e9 对 P-S0 300 是 16.8%，P-S0 300 对 P-D 300 是 17.8%）。
- 公式：最小差 ≈ 2.8 × √(不一致率 / 题数)。
- D 和 C 的 SFT 不同，不一致率可能更高。按 25% 算，合起来约 5.8 个百分点。

### 3.2 动作成功率（按任务族）

| 项 | 规定 |
| --- | --- |
| 题集 | eval_test_v2：每族 50 道（遮挡族 42 道）；验证集每族 75 道（遮挡族 38 道）作参考 |
| 比较、检验 | 同 3.1，每族分别做；6 个族 × 2 个比较，用 Holm 法校正 |
| 判定"有差异" | 校正后 p < 0.05，且差 ≥ 10 个百分点，且 S0、D 同号 |
| 能测出的最小差 | 每族约 9–13 个百分点（合起来，每族 100 个"题 × RL"；不一致率 10%–22%）；单个 RL 约 13–19 个百分点 |

- 按族的结论只说方向，不作主要结论。

### 3.3 探针：四类题（`goal_now`、`goal_after`、`occluded_now`、`occluded_after`）

| 项 | 规定 |
| --- | --- |
| 题集 | `exps/transition_qa_20261019b/p1_probe.jsonl`（2026-10-21，952 道）：`goal_now` 200、`goal_after` 200（Yes、No 各 100）、`occluded_now` 41、`occluded_after` 71；同一份题给所有组、所有检查点 |
| 指标 | goal 两类：总准确率（Yes、No 各半，所以总准确率就是两种答案准确率的平均）。遮挡两类：**平衡准确率**（完全 / 部分 / 没有三种答案各自的准确率的平均，随机 33.3%），因为答案不均（`occluded_now` 19 / 15 / 7，`occluded_after` 22 / 22 / 27），总答"完全"的总准确率就有 46.3% / 31.0%。另报：总准确率、按答案分开的准确率、格式不合规率、"只看文字"的两条基线（原版 7B 不看图、`shortcuts.py` 的规则） |
| 检查点 | SFT 挑出的 epoch、RL 第 300 次（S0、D 各一个） |
| 比较 | D − C、D − C0，每类分别；同一道题配对：goal 两类用 McNemar 检验；遮挡两类的平衡准确率用按题配对的自助法（2,000 次）求 95% 置信区间和双侧 p 值；α = 0.05 |
| 判定"有差异" | p < 0.05，且差 ≥ 10 个百分点（遮挡两类看平衡准确率的差），且 S0、D 两个 RL 同号 |
| 能测出的最小差 | 按第三版探针实测的逐题不一致率（`DIAG3_PROBE.md` 结论第 7 条；用原始 7B 对 SFT e9，训练数据不同，最像 D 对 C）：`goal_now` 约 6、`goal_after` 约 7 个百分点；`occluded_now` 总准确率约 28、`occluded_after` 约 16。偏保守地按不一致率 50% 估：goal 两类各约 14，遮挡两类约 31 / 23，平衡准确率约 34 / 24；四类合起来（512 道）总准确率约 9。判定线"差 ≥ 10 个百分点"对 goal 两类足够；遮挡两类各自太粗，**合起来看**（112 道，平衡准确率约 19），并只作方向（下一段） |

- 最小差的算法同 3.1：最小差 ≈ 2.8 × √(不一致率 / 题数)；平衡准确率按每种答案的题数分别算再合（`occluded_now` 只有 7 道"没有"，所以它最粗）。遮挡两类合起来（112 道，三种答案 41 / 37 / 34）平衡准确率约 19 个百分点。
- 2026-10-21 起遮挡两类的题少了一半左右（深度核对去掉了框说挡住、渲染里没挡住的题），所以遮挡的比较改为：两类合起来报平衡准确率的差和 95% 置信区间，只在差 ≥ 20 个百分点、S0 和 D 同号时说"有差异"，否则只报方向。

- **起点**（第三版探针，`DIAG3_PROBE.md`）：所有现有模型在两类 goal 题上几乎只答 No。
  - 答案是 Yes 的题答对 0%–19%，答案是 No 的题 89%–100%（每类 100 道）。
  - 原始 7B 两类都是 Yes 0%、No 100%；不看图的原始 7B 也一样。
  - 遮挡两类（2026-10-21 深度核对之后，112 道合起来的平衡准确率）：原始 7B 42.2%，训练后还在的 4 个检查点 31.5%–36.3%，随机 33.3%。实测的逐题不一致率（原始 7B 对 SFT e9）：`occluded_now` 43.9%、`occluded_after` 29.6%，最小差约 29 / 18 个百分点。
  - **检查点被删了**（2026-10-21 腾配额时）：第十一轮只剩 SFT e1、e9，P-S0 300，P-D 150；**C0（`interiorgs_v10_train_r12a_20261019`）只剩 P1-S0 第 250 次、P1-D 第 100 次**（两个 RL 各自挑中的），本节规定的"RL 第 300 次"在 C0 已经没有了。C0 的探针只能用这两个检查点和 SFT e9 跑，定稿时要改这一条，或者 C0 只作参考。矩阵各组的探针由补丁 0002 的 `diagnostics` 步在清理（`retain`）之前跑，不受影响。
  - 23 个检查点的总准确率 40.5%–43.2%，随机猜 40.1%。
  - 所以"答案是 Yes 时的准确率"是看 D 有没有学会判断已满足的直接指标。
- **D 练过 P1**：探针题和 P1 是同一种格式，D 在探针上会直接占优。这一节回答"D 学会了没有"，不回答"学会了有没有用"；有没有用看 3.1、3.2。
- **C0 的探针**：第十二轮的检查点用定稿后的探针跑一次（推理，单卡约 0.7 卡时）。

### 3.4 失败拆解："只差一个条件"的失败里，差"关系"的比例

| 项 | 规定 |
| --- | --- |
| 定义 | `eval/diagnostics/failure_breakdown.py`：12 个动作用完、最好的回合只差一个条件的题；按主线第十二轮的三组分法（画面 / 看清楚 / 关系）看差的是哪一组 |
| 题集 | eval_test_v2（292 道）为主，验证集参考 |
| 指标 | ① 差"关系"的比例（分母是只差一个的失败）；② 差"关系"的只差一个的失败占全部题的比例。①是用户要的指标；成功率变了分母会跟着变，所以另报②，②可以逐题配对 |
| 现状（C0） | 评测集 SFT e9 61%（111 道里 68 道），P-S0 300 63%（122 道里 77），P-D 300 60%（108 道里 65）；验证集 53% / 57% / 57%（`DIAG1_FAILURE.md`）。主线说的"约三分之二"和评测集的数接近 |
| 比较 | D − C、D − C0；①两比例的 z 检验（S0、D 合起来），②逐题符号检验 |
| 判定"下降" | ① p < 0.05 且下降 ≥ 10 个百分点；② p < 0.05，S0、D 同号 |
| 能测出的最小差 | ①合起来每组约 230 道失败，约 13 个百分点；②约 5 个百分点（按不一致率 20% 估） |

- 投影族、视野族"只差一个"几乎从不差"关系"，只差"画面"或"看清楚"；差"关系"的失败集中在遮挡、等距、绝对距离、画面占比四族。所以这一项实际上看的是这四族。

## 4. 假设和读法

- **H1（主）**：D 的动作成功率高于 C（3.1）。
- **H2**：D 在四类探针题上，尤其是"答案是 Yes 时"，准确率高于 C、C0（3.3）。
- **H3**：D 的"只差一个"失败里差"关系"的比例低于 C、C0（3.4）。
- 读法：
  - H2 成立而 H1 不成立：学会了回答转移题，但没有用到动作上。
  - H1 成立而 H3 不成立：提高来自别处，不是关系判断。
  - 三者都不成立：P1 这种形式没用（在这批题和这个训练量下）。

## 5. 报告格式

- 每个指标一张表：C0、C、D 的值；D − C、D − C0 的差，95% 置信区间、p 值；S0、D 两个 RL 分开再合起来。
- 主指标的 p 值不校正；按族的结果用 Holm 校正；其余是次要指标，不校正，但写明一共比较了几次。
- 一律写清"多少道题里多少道"。

## 6. 不做的事

- 不按评测集挑检查点、挑题、挑族之后再下结论。
- 不用训练时的验证损失代替成功率下结论。
- 不把 E 组、D_noP0 组混进 D 的比较；它们各自单独报告。
