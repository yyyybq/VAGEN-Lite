# 分析 4：迁移表（探索性）

The tool's rows are "which question groups a run trained": D and D_noP0 trained P1's three groups at once, so its 3 x 3 would repeat one row three times.  Reported instead, both on the pre-registered checkpoints (m3_supp_rest's models): the columns, action success on the test set (292 tasks) per task group; and the rows, P1-probe accuracy (838 questions) per question group (投影: left_right; 距离类: closer, distance_bin, height_bin; 可见性类: occluded, both_in_view; goal and action_between apart).  Differences in points pooled over the four (seed, side) pairs, the sign test on the (item, pair)s only one side gets, 95% intervals from m3_prereg_rest's bootstrap; Holm over the 6 tests of each table. Writes OUT/a4.{json,md}.
