### 0.1 特权 critic（包 p1tgae_fc，标准 v10_p1tgaefc_S0 / v10_p1tgaefc_Dcond）

- 代码在 qwen3-main-dev（40538eee 起），默认关。关着的时候，现有包、配置、环境和检查点都和以前逐字节相同，CPU 检查会核对。
- **不启动 critic worker**（critic.enable false）。每回合的价值由训练进程（driver）里的一个三层 MLP 给出，代码在 `vagen/feature_critic.py`。
- **输入**：环境的真值，取在这一回合的观察渲染时的位姿上（env critic_features，`vagen/envs/active_spatial/critic_features.py`），共 29 维：
  - 剩余最少动作数 d：从这道题的距离表查，本格查不到时取 26 个邻格里最小的；编码为 min(d, 12) / 12，另加一位"查不到"标志；
  - 方位扇区：题目物体 A 在前 / 右 / 后 / 左，或"无"（站在物体投影内）。口径同 grounding 探针的 `truth`。
  - 距离条件：只有 absolute_positioning 有，分太近 / 合适 / 太远；其他题型记"无"。
  - 回合序号：one-hot，共 12 位。
  - 题型：one-hot，共 6 位。
- **输出和损失**：两个输出。
  - 整局成败的 logit，用二元交叉熵；
  - 这一局剩下的回合数（含本回合）除以 12，用平方误差，权重 1。
  - "剩余步数回归"按"这一局实际还剩几个回合"实现。剩余最少动作数 d 已经是输入，再回归它没有意义。
- **价值**：V = a·σ(logit) + b·剩余回合 + c + e·Φ_t。
  - 每次更新后，用缓冲里的蒙特卡洛回报（从本回合到局末的回合奖励之和，γ = 1）做岭最小二乘，重估 a、b、c、e。
  - Φ_t 是环境在这个位姿上的势（shaping score），随特征一起记下，只进读出、不进 MLP（readout_phi）。
  - 为什么加 Φ_t：V4 的进度奖励是势差，剩余回报里有一项 −3.33·Φ_t；只靠"成功概率 + 剩余回合"表示不了它，门 A 可能因为读出的形式而不过。S0 下这一项拟合出来约为 0。
  - 第一次更新前 a = b = c = e = 0，所以价值是 0。
  - 每次更新另记一个线性上限：缓冲里的回报对 29 维原始输入、两个输出和 Φ_t 做岭回归，记样本内 EV（`critic/feature/ceiling_ev_buffer`）。门 A 不过时，用它分清是读出太窄还是特征不够。只报，不进判定。
- **训练**：
  - 每次更新，把这次全部候选局（过滤前）的回合加进缓冲。缓冲只留最近 8 次更新。
  - 在缓冲上训 4 遍，小批 256，Adam，学习率 1e-3。
  - 隐层 128，岭系数 1e-4，初始化用 data.seed。
- **读值顺序**：第 t 次更新的价值，在这次更新之前算，用的是第 t − 1 次训完的 MLP 和读出，所以对这次的批是折外的。
- **其余照 p1tgae_c2**：λ 0.95、γ 1，turn_gae 估计器，过滤后再白化，keep 过滤器，预热 30，策略的学习率、KL 系数、熵系数都不变。
- **检查点**：MLP、Adam、读出系数、缓冲和随机数状态一起存进 `feature_critic.pt`。续训没有这个文件就拒绝。
- **环境**：只在训练环境里开 critic_features；验证环境和评测不开。奖励、成功判定、终止条件都不变。
  - 特征算不出来时（比如表读不了），环境记 None 和原因，这一步的奖励、成败、结束都照环境自己的；训练进程遇到没有特征的回合就报错停下，不悄悄跳过。
- **代码和检查**：qwen3-main-dev 40538eee，加两人审查的修正 866daa91（两人都没有阻断项）。CPU 检查 `analysis/ppo2_20261113/fc_check/job2`：全套测试；现有五个 plan 的 rl-config 输出和上一次逐字节相同；新 plan 只差特权 critic 的键和题池；3,000 道题在起点位姿上查表得到的 d 都等于 d\*。

## 第 0 关：表征探针（诊断，不设门）

- **问题：** 三次 critic 试点的价值网络都从 C0 SFT e8 起。critic 读值的位置上，这个起点的隐状态线性能读出多少价值相关的东西？
  - 读得出：critic 学不起来，更可能是优化和目标噪声的问题。
  - 读不出：表征里没有这些信息，只能靠特权特征（第 1 关）。
- **局：**
  - C0 SFT e8 在 b3000 的 3,000 道上各采样一局，温度 0.8、top-p 0.92，同 RL 训练的采样。
  - V4 环境，开 critic_features，经只评测的训练链提交。
  - 每回合记下：真值特征、回合奖励、送进模型的帧、模型的输出。
- **隐状态：**
  - 用 HF 前向，bf16，对整局做 teacher forcing，拼接方式同训练（concat）。
  - 取每回合第一个生成 token 前一位（critic 读值的位置）。
  - 取第 9、18、27、36 层和最后归一化之后的输出，共 5 处。
- **目标：**
  - G_t：V4 的蒙特卡洛剩余回报（主目标）；
  - 整局成败；
  - 剩余最少动作数 d；
  - 方位扇区；
  - 距离条件（只用 absolute_positioning 的回合）；
  - 剩余回合数。
- **探针：**
  - 线性：连续目标用岭回归，类别用逻辑回归。
  - 5 折交叉验证，按场景分组；正则系数在折内选。
  - 报折外的 EV / R²、AUC、准确率，类别目标另报多数类基线。
- **对照（同一批状态、同样的折）：**
  - 第 1 关的 29 维特征训同样的三层 MLP，看 G_t 的 EV。这是"特权信息能给多少"。
  - 只用回合序号加题型的线性回归。
- **读法（写死）：** 看最佳一层 G_t 的折外 EV。
  - ≥ 0.3：表征里线性可读。
  - < 0.1：读不出。
  - 在两者之间：弱。
  - 其余目标只报数。
- **代价：** 约 5–7 卡时，上限 10。
  - 采样：约 3–4 卡时，加一张渲染卡。
  - 提取：约 0.5 卡时。
  - 拟合：CPU。
- 第 0 关的结果不影响门 A 的判定，也不决定第 1 关交不交。
