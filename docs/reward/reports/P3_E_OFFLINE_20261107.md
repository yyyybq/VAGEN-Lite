# 奖励线 → 主线：实验 E 的离线结果（2026-11-07）

用户 11-07 定的是"1 甲"：E 不跑自己的两臂，用主线 3A 的检查点。奖励线只做两件不占卡的事：
- 转身占比的口径对账（对话历史对齐）；
- B 的运行按 3A 规则离线算被挡占比的表。

## 结论先说

- **密集臂并不比稀疏臂更容易被挡。**
  - 按 3A 的规则（脚印圆 r 0.25 m，0.1–1.0 m 高度带，只管转身）离线重放。
  - 本线 B 六个验证集最好检查点，转身被挡 48.2%–51.0%；起点 C0 e8 48.9%（v2 验证 413 + 测试 292，共 705 道）。
  - 密集减同种子 S0：V4 −1.6，O +1.2，O-keep 种子 1 +0.9，O-keep 种子 2 +0.4 个点。95% 区间都含 0。
- **被挡的比例几乎不随模型变。**
  - 主线 C0 的四个 RL 在 49.5%–51.0%；不带历史的三个在 48.7%–51.1%。
  - 约一半的转身被挡，是位置决定的：主线算过 r 0.25 m 时约 50.6% 的起点本身就挡着；本线各模型在起点处的转身被挡 45%–54%，走动以后 48%–53%。
  - 各臂之间"每动作被挡的转身"的差，跟的是转得多不多：V4 种子 1 比 S0 少转 5.5 个点，每动作被挡少 3.2 个点；O-keep 两个种子多转 1.1 / 0.6 个点，每动作被挡多 0.9 / 0.5（区间含 0）。
- **"SFT 约 10%、RL 38%–52%"这个差来自对话历史，** 不来自环境、身体或计数口径。
  - 带历史对齐后，同三个模型在 InteriorGS 和 RoboCasa 机器人身体下只差 0.5–1.7 个点。
  - 都不带历史时，两种环境里都是 SFT 约 10%。

## 算了什么

1. **被挡占比：**
   - 把主线的 `turnblock_exposure.py` 原样复制，代码根换成 q3dev e0269bc3 的 git archive。
   - 跑了本线的 rw_s0_150、rw_g_250、rw_o_200、rw_ok_250、rw_s2s0_300、rw_s2ok_250，都核过是各自验证集 413 道上最好的。
   - C0 e8 和主线四个 C0 RL 作复现；下游 a_nohist 的三个作不带历史的参照。
   - 复现：主线 5 个模型的全部输出和主线的 `turnblock_exposure_out.json` 逐键相同。

   - 登录节点 1 个核，约 3 分钟。
2. **转身占比**按三个维度重算：
   - 计数：写出的全部动作，或执行的动作（含被挡的，成功局截到达成那一步）；
   - 输入：带或不带历史；
   - 环境：InteriorGS 705 道，或 RoboCasa 585 个实例。

## 读法

- **问题"密集是不是比稀疏挡得多"：按 3A 的规则离线看，不是。** 每次转身被挡的概率在各臂之间差不到 2 个点，区间都含 0。
- 各臂每动作被挡多少，几乎只看转得多不多。本线的密集臂转身不比 S0 多，V4 种子 1 还少 5.5 个点。
- 带历史时，RL 比 SFT 只多转 5–8 个点，两种环境都一样：InteriorGS +5.6 / +7.5，RoboCasa 身体 +6.2 / +6.9。

## 对 3A 意味着什么（只列事实）

- 3A 训练和评测都带历史。在这个设置下，C0 e8 转身 29%，RL 33%–37%；不论哪种奖励，转身都有约一半会被圆挡住。
- 主线自己在环境里评的数（G1 / G2，筛过的 674 道；奖励线只按验证 + 测试合并，没做检验，不是本线的结论）：
  - C0 的五个模型被挡 51.0%–57.6%，高于上面的离线数。题集不同（674 道对 705 道），差在哪里是推断：可能是被挡后在原地连着转，每次都被挡。
  - 3A 那一对第 50–300 次：qw3fpd 52.7%–55.5%，qw3fps0 49.5%–53.2%。同一次的 V4 − S0 是 +1.0 到 +6.0，6 次都为正。
  - 同时 qw3fpd 转身占比 21%–28%，比 qw3fps0 的 25%–35% 低。
- RoboCasa 身体下每次转身被挡的比例：带历史 21.7%–35.3%，低于 3A 圆的约 50%；不带历史 39.3%–52.3%。
- 下游 N3 的 (f) 档（转身不算碰撞，Q3RD − Q3S 比 (d) 档补回 +2.4 个点，N3_TIER_F_20261105）是在不带历史的口径下测的。在这个口径下 RL 比 SFT 多转得多：InteriorGS 11.2 / 24.5 / 37.3，RoboCasa 10.0 / 22.6 / 38.4。

## 限制

- 离线数不是反事实：轨迹是在旧规则下走出来的（转身从不被挡），工具只数"在记录的位置转身会不会被挡"。真在 3A 下，策略会看到被挡的反馈，第一次被挡之后轨迹就分叉了。
- 每个运行只取验证集最好的一个检查点。同一运行不同检查点之间转身占比能差约 10 个点（MIX_SCREEN 5.3：rw_g 19.5–30.0，rw_s0 21.1–33.2），比表 B 里密集和稀疏的差还大。
- 本线的 rw_* 在 3,000 道子集上训，主线那几对在 10,798 道上训；q3s0_100 和 q3d_300 不是同一个训练步数（q3s0 第 150 次走样被停）。
- InteriorGS 和 RoboCasa 的题目、场景、碰撞判法都不同；跨环境的格子只能描述，不能做配对检验。
- 任务书里"N1 不带历史 SFT 约 11%"：N1 (d) 档的 Q3S 实际是 10.0%（Qwen2.5 S 9.3%），11.2% 是 InteriorGS 不带历史的数；"RL 38%–52%"是 Q3RD 38.4、RS 41.1、RD 52.4，不含 Q3RS 的 22.6。
