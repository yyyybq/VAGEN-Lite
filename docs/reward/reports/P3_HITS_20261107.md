# 最优动作命中率：已有运行的重放（2026-11-07）

**结论：** RL 几乎没提高"每个动作是不是表上的最优动作"这一项。

- 本线 9 个运行第 50/100/150 次的动作命中率平均是 42.2%–45.0%，起点 C0 e8 是 42.2%，最多高 2.7 个点。
- 半数以上的动作不是最优的，这正是 B 的标签要推的地方。
- 命中率和成功率一起动：同一运行内，各检查点相对本运行均值的偏离，相关系数是 0.72（76 个检查点）。
- 密集减同种子 S0 的命中率差，和成功率差同向。

这张表只作 B 的对照，不是新判据。B 的过线判据仍是 PREREG_P3_B 第 5 节的成功率和出错率。

## 1. 做了什么

- **工具：** `reward/turn_metrics.py`（reward-design bb8a5b16）。
- **重放对象：** 原评测轨迹，按距离表判每个执行了的动作。
  - "命中"：动作让表上距离减 1。被挡的移动不算命中。
  - **动作命中率** = 命中的动作 / 判过的动作。
  - **回合命中率** = 动作全部命中的回合 / 判过的回合。
  - 口径见 PREREG_P3_D 第 5 节。这里只看执行了的动作，不看写法，所以和 B 训练日志里"对的回合"口径不同，分开报（PREREG_P3_B 第 6 节）。
- **对象：**
  - **本线：** 9 个运行的全部检查点，加起点 C0 e8，用评测集 705 局（验证 413 + 测试 292）。rw_s0 只剩第 50–200 次的 4 个检查点。
  - **矩阵 D 组：** m3ds1d / m3ds1s0 / m3ds2d / m3ds2s0 的全部检查点，加起点 m3d_sft e9，用筛过的 674 局（382 + 292）。

  两组题不同，本线和矩阵的数不直接比。
- **核对：**
  - 54,215 局重放和原轨迹逐局相同，0 局重放出错，0 处终点位姿不符。
  - 共判了 488,627 个动作、363,173 个回合。
  - 工具提交前核过：旧有各项和上一版逐项相同。
- **输出：** `reward_runs/analysis/27_hits/`，表为 `turn_metrics_hits_line.md` 和 `turn_metrics_hits_matrix.md`。
- **代价：** 登录节点 CPU 约 75 分钟（3 个进程，nice 19），不占卡。

## 4. 怎么读，局限

- **相关不说明因果。** 成功的局按定义含更多让距离减小的动作，所以命中率和成功率一起动，有一部分是定义带来的。
- **最优动作可能不止一个。** 几个动作都让距离减 1 时，都算命中，所以动作命中率不是"选对唯一答案"的比例。随机选动作的命中水平这里没算。
- **对 B 的用处：**
  - B 的两臂训完后，用同一工具、同样的检查点算这张表。
  - rw_dg_s0 对 rw_s0（42.2%），rw_dg_g 对 rw_g（43.8%）。
  - 如果成功率过了线，命中率却和对照差不多，说明标签没按设想起作用，成功率的差要另找来源。这一条只用于解释，不改判据。
- **和训练日志对照：** B 第二轮核对从 D 的训练轨迹算出"对的回合"约 36.8%（评测）和 39.3%（训练），与这里实验 D 三个运行（rw_s2g、rw_s3s0、rw_s3g）37.8%–38.7% 的回合命中率是同一量级，口径不同（训练日志还要求写法规范、写的等于执行的）。
