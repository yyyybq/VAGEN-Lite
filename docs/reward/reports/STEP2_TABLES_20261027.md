## 3. 粗筛收紧（用户补充要求第 3 条）

**成功规则**：
- 环境的成功要求每个"必须看清"的物体，以及它描述里用到的参照物，都至少有一面清楚可见（`target_visibility.REQUIRED_VISIBLE_SLOTS`）。各族要求：
  - 投影关系、视野包含、等距：两个物体都要；
  - 绝对定位、占画面：只有一个物体；
  - 遮挡对齐：只要遮挡物，被挡住的目标不要求可见。
- 所以按"所有题目物体都在视野锥里"收紧，只对前三族起作用；后三族照旧（遮挡对齐不能收紧，绝对定位和占画面只有一个物体）。参照物不在"题目物体"里，没有加进来。
- **为什么不会漏判**：一面清楚可见，要求 40% 的采样点在相机前方、落在画面内。所以物体至少有一点在视锥里，它的外接球一定碰到粗筛用的视野锥（画面对角线的半角再加 5°）。只要有一个必须看清的物体不满足，这个状态就不可能成功。

4. **和反向扩展表比**：
