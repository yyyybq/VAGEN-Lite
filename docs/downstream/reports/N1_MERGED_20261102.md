# N1 加固：两套合并 600 个实例的结果（2026-11-02）

> 依据：你 11-02 晚决定 3："用新场景、新种子再生成 300 个实例（六类各 50），8 个模型重评，和原 300 合并报 600"。N1 的原报告见 [N1_RESULTS_20261031.md](N1_RESULTS_20261031.md)，设计见 [N_DESIGN_20261028.md](N_DESIGN_20261028.md)。

## 结论

1. **N1 里"RS 比 S 低 4.7"在新的 300 个实例上没有复现，那一条要撤回。**
   - 新的 300 个上，RS − S 是 +1.7（p = 0.44）。
   - 合并 600 个，RS − S 是 −1.5（95% 区间 −3.9 到 +0.9，p = 0.28）。
2. **合并后，四个 RL 模型和各自的 SFT 都分不开，没有一个方向显著。**
   - RS − S −1.5（p = 0.28）；RD − S +2.3（−0.4 到 +5.1，p = 0.12）。
   - Q3RS − Q3S +0.5（p = 0.74）；Q3RD − Q3S +0.3（p = 0.90）。
   - 主线自己的评测上（X4，验证 + 测试 705 题），RS − S +5.8、RD − S +5.1。RS 在这里的区间上限 +0.9，排除了 +5.8 那么大的增益；RD 的上限 +5.1，排除不了。
3. **主线训练过的六个模型都明显好于各自的底座，两套各自也都成立。**
   - 合并 600：S − B +11.0、RS − B +9.5、RD − B +13.3，p 都 < 10⁻¹²；Q3S − Q3B +8.8、Q3RS +9.3、Q3RD +9.2，p 都 < 10⁻⁸。
   - 两套里最弱的一项是新一套的 S − B：+6.3，p = 0.0005。
4. **但两套的绝对成功率差得不小，单独一套 300 个不够可靠。**
   - S 在 N1 上 15.7%，在新一套上 8.3%。
   - S − B 在两套分别是 +15.7 和 +6.3。两套之差 9.3，p = 0.00065；10 个"两套之差"做 Holm 校正后 p = 0.0065，是唯一还显著的一项。
   - 不是两套难度分布不同：最短走法平均 6.50 对 6.69 个动作，起点就过了可见门槛的实例 44 对 48。
   - 也不是同一场景几个实例不独立造成的：配对差的区间，整场景重抽和按实例算的几乎一样宽。
   - 原因未核实。猜测：两批重置种子抽到的厨房布局不同，而 S 对布局敏感。
   - 所以论文用合并的 600，并写明两套之间有这么大的差别。
5. **探索性：画面占比这一类，RS 比 S 低 13 个百分点，两套方向一致。**
   - 合并：只有 RS 成功 1 个，只有 S 成功 14 个，六类内 Holm 校正后 p = 0.006。两套分开：N1 S 11/50 对 RS 3/50；新一套 S 10/50 对 RS 5/50。
   - RD 在这一类也低 9（p = 0.11）。
   - 其余五类、Qwen3 的两个 RL 模型都没有这种情况。

## 两套各是什么

| | N1（10-31） | N1 加固（11-02） |
| --- | --- | --- |
| 场景 | X0 的 26 个任务、X0 的前 150 个场景（重置种子 1000 起） | X0 的 26 个任务 × 新重置种子 3000–3006，共 182 个，都做完，没有超时、没有出错 |
| 候选和取用的随机种子 | 20261031 | 20261102 |
| 实例 | 300 个，六类各 50，来自 93 个场景、26 个任务 | 300 个，六类各 50，来自 91 个场景、26 个任务 |
| 门槛附近 | 118 个 | 108 个 |
| 评测 | 8 个模型各 300 回合 | 同左；8 个任务的启动脚本除路径外和 N1 逐字相同（已核对），模型路径相同 |

- **实例：** 一个场景里的一类任务（比如"让咖啡机出现在虾的右边"），带固定的起点。
- **门槛附近：** 连余量最大的成功位姿也只是勉强过某道门槛，范围见 `n_env.NEAR_BANDS`。
- **规则同 N1：** 贪心解码，每个模型每个实例一回合，每回合最多 12 轮、12 个原子动作。
- **实例 ID 不重复：** 两套的实例 ID（`{任务}_s{种子}_{类型}`）没有重复，合并时代码会检查。

## 行为（合并 600）

- **被挡的动作占比：** RL 模型都比 SFT 高。RS 35.5%、RD 37.1%，S 21.7%；Q3RS 28.4%、Q3RD 31.5%，Q3S 22.4%。两套方向一致。
