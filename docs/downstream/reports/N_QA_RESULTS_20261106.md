## 4. 跨模型

做法：沿用分析脚本已有的配对。对每一对模型 A、B，取 A 答对、B 答错的实例，比较"A 成 B 败"和"B 成 A 败"的次数（精确二项，同 McNemar）。每个子集 56 个有序对；Holm 校正在每个子集的 56 个有序对里做（两种次数都为 0、没法检验的对按 p = 1 算；和 `tables.md` 的差别见第 7 节）。

表头："指向答对者"是"A 成 B 败"多于"B 成 A 败"（A 是答对的一方）；"反向"相反；"持平"是两种次数一样。

| 子集 | 回合 | 指向答对者 / 反向 / 持平 | 未校正显著（指向 / 反向） | Holm 校正后（指向 / 反向） |
| --- | --- | --- | --- | --- |
| 左右 | 带历史 | 16 / 27 / 13 | 0 / 10 | 0 / 4 |
| 左右 | 不带 | 25 / 19 / 12 | 0 / 2 | 0 / 0 |
| 远近 | 带历史 | 26 / 17 / 13 | 5 / 2 | 2 / 0 |
| 远近 | 不带 | 26 / 16 / 14 | 4 / 0 | 0 / 0 |
| 第一步题全部 | 带历史 | 23 / 28 / 5 | 12 / 8 | 9 / 4 |
| 第一步题全部 | 不带 | 32 / 17 / 7 | 9 / 2 | 1 / 0 |
| **答案其他（主读）** | 带历史 | 18 / 24 / 14 | 1 / 1 | 0 / 0 |
| **答案其他（主读）** | 不带 | 19 / 17 / 20 | 0 / 0 | 0 / 0 |

- **未校正显著的全是训练过的模型和底座的配对，而且都是训练过的一方成功多，** 不管答对的是谁。
  - 例：左右题带历史，Q3B 对、Q3S 错的 63 个实例上，Q3S 成 Q3B 败 11 次，反过来 0 次（未校正 p = 0.001，56 对内 Holm 校正后 0.051）。
  - 推断：这些配对量出来的是两个模型本来会不会做，不是会不会答。
- **训练过的模型之间：** 同族 12 个有序对（S/RS/RD 内部、Q3S/Q3RS/Q3RD 内部）、跨族 18 个，4 个子集、两套回合都没有一对未校正显著（跨族最小 p = 0.062）。"A 成 B 败""B 成 A 败"的次数，同族 0–5 次，跨族 0–12 次。推断：这些对的成功率相近，计数又小，是检验力不够。
- **加的对比检查（扣掉两个模型本来的成功率差距）：** 对每一对模型（不分先后，28 对）：先在"A 对 B 错"的实例上算 A 的成功率减 B 的，再在"B 对 A 错"的实例上算同样的差，两者相减。两个模型本来的成功率差距在两边都有；假定它在两边一样大，相减后就抵掉了（这个假定未核实）。剩下的大于 0，表示答对的一方做得相对更好。按代数，这个量等于 A、B 各自在这些分歧实例上的"答对减答错"之和。
  - 主读：带历史 11 对大于 0、13 对小于 0，不带 12 对、14 对，没有方向。区间不跨 0 的各 1 对：带历史 RS 和 Q3B 一对在 0 以下（−15.7，−32.3 到 −3.4），不带 RS 和 Q3RS 一对在 0 以上（+20.2，+3.8 到 +40.8）。
  - 第一步题全部：不带历史 28 对里 26 对大于 0，区间在 0 以上的 1–2 对（B 和 Q3S；B 和 RD 一对的下限贴着 0，随重抽种子进出）；带历史 13 对大于 0、15 对小于 0，区间在 0 以上的 3 对（B 和 RD、B 和 Q3S、B 和 Q3RD，B 带历史只成功 11 个）。
  - 左右、远近有方向：左右带历史 8 对大于 0、18 对小于 0，6 对区间在 0 以下（5 对有 Q3B，另 1 对是 Q3RS 和 Q3RD），不带 19 对、8 对，没有区间不跨 0 的；远近带历史 17 对、8 对，不带 18 对、8 对，区间在 0 以上的 5 对、4 对，几乎都是 B 和别的模型的配对。左右带历史偏负，和第 3 节同一模型内的结果同向；远近偏正，主要来自有 B 的配对（B 带历史只成功 11 个）。

## 6. 限定和推断

- **检验很多，没有总校正。** 同一模型内每套回合 72 格（8 个模型 × 9 个子集），彼此不独立。不带历史有 10 格未校正 p < 0.05，带历史 3 格。72 格里光凭偶然约有 3.6 格 p < 0.05；但格不独立，很多格成功数太少，Fisher 检验的 p 根本到不了 0.05 以下，所以偶然期望比 3.6 还小，这个比较只作粗看。推断：带历史的 3 格和偶然水平差不多；不带历史的 10 格比偶然多，但多在第一步题全部和后退题这些互相嵌套的子集上，还有方向反的格（B、Q3B），按第 3 节的规则不算发现。
- **p 把题当独立的。** 1,000 道题来自 180 个场景，同一场景的题彼此相关；第一步题更甚，539 道只有 200 张不同的起点画面（第 1 节）。只有区间是按场景重抽的，p 没考虑这一点，推断会偏小，只靠 p 的说法要打折扣，以区间为主。也有反过来的格：Q3S 带历史第一步题全部，区间 +0.7 到 +13.6，不含 0，p 却是 0.050。区间和 p 不一致的格，不当结论。区间端点离 0 不到 0.5 个百分点的格，"含不含 0"取决于重抽的随机性（第 3 轮核查换种子看过几处），也不当结论。
- **成功率低，检验力弱。** 主读 138 道上成功只有几个到十几个，"没测到关系"不等于"没有关系"。区间以外的范围见第 3 节。
- **"答对"和"做成"可能有共同原因，不能当因果读。** 后退题上的正向差，可能是起点本身好判断、也好走；也可能是同一个后退倾向同时出现在问答和回合第一步里（第 3 节加的检查和后者相合）。按最短步数分层后，第一步题全部在 6 步以上一档还有正向差（第 3 节），所以"起点短"解释不了全部（推断），别的难易没查。两种解释都未核实。要分开，得在同一实例上换问法或换起点，这批数据做不到。
- **两选一的题，答对不全是会。** 主读 138 道上 50% 是瞎猜的水平。按"会的全对、不会的瞎猜、读不出的不算猜、猜中和成败无关"粗算，训练过的 6 个模型答对的 69–79 道里，真会的约 10–36%（S 12%、RS 24%、RD 10%、Q3S 29%、Q3RS 32%、Q3RD 36%，平均约 24%），其余约 64–90% 可能是猜中的。若把读不出的也当猜错，真会的只有 0–25%（平均约 14%）。所以"答对一侧"里混着猜中的，会把差往 0 拉（推断）。
- **问的画面不同。** 物体题问终点视角，第一步题问起点视角。回合里要先走到终点，才看得到物体题问的那个画面，所以物体题答得对不对和回合成败本来就不直接相连。
- **干扰项种类不是随机分的，两组起点难易不同（已核实）。** 被挡组的最短走法更长（平均 7.6 对 5.9 步），一部分是搜索深度上限造成的（第 1 节）。答案其他的两格里，被挡组的回合也更少成功（训练过的 6 个模型平均，没做检验）：带历史 3.0% 对 12.4%，不带 0.7% 对 5.6%；答案后退的两格差不多（带历史 21.6% 对 23.3%，不带 15.0% 对 15.1%）。所以四格和回合成败一起读时，混着起点难易。
- **跨模型配对受两边本来成功率的影响。** 第 4 节的计数不能直接读成"会答的做得好"，对比检查只作参考。
