# X5 未见任务：结果（2026-10-29）

> 依据：你 10-26 的决定和 10-27 确认的任务清单（设计见 [X_DESIGNS_20261026.md](X_DESIGNS_20261026.md) 的 X5 一节）。E1 四个最终检查点都评完了，结果 10-27 11:52 已出，这份报告晚交了。

## 结论

1. **没训练过的任务，四个起点都几乎不会，起点之间也没有差别。**
   - 16 个未见的原子任务（主评，每个起点 320 回合）：成功率 B 6.2%、S 6.2%、RS 5.6%、RD 4.1%。
   - 和 B 逐任务比都不显著：按任务平均差 −2.2 到 0.0 个百分点，Wilcoxon p ≥ 0.25。
2. **16 个未见的组合任务**（补评，每个 319 回合）：成功率 0.3%–1.2%，基本都做不成。
3. **主线的空间训练没有让下游策略更会泛化到新任务。** RD 的点估计还最低，但不显著。

## 做法

- **任务**：从 RoboCasa 1.0.1 的登记表里选 E1 训练数据（target50）之外的任务。按名字排序后用固定种子 0 打乱，依次在 target 场景里试重置，前 16 个能正常重置的进清单。原子、组合任务各 16 个。
  - 清单在 `downstream/x/x5_tasks.json`；选法在 `downstream/x/x5_tasks.py`，选的记录在 `downstream_runs/x/X5/select_*.log`。
- **评测**：E1 四个最终检查点，每个任务 20 回合（种子 1000–1019），和 E1 同一套设置（计划 `downstream/x/x5_plan.json`）。
- **统计**：`downstream/x/x5_analyze.py`，逐任务配对，同 E1；结果在 `downstream_runs/x/X5/results/`。
- **卡时**：4 个 8 卡评测，每个约 3.3–4.9 小时，共约 120 卡时（按任务时长估，未核实）。
