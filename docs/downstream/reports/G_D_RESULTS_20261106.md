  - 按设计"水平"那条规则（某个模型的差的区间不含 0），六个训练过的模型都算"改变了 N1 主表的结论"，两个底座不算。

  四组的"带减不带"，Holm 校正后都是 0.95。

  - "带减不带"指带历史时的差减去不带时的差，看两个模型的差是变大还是变小。
  - 按设计写定的判定，两族的"RS − S 回来了"都是否，"RD − S 变了"也都是否。"回来了"指带历史时 RS − S 的区间在 0 以上，而且"带减不带"的区间也在 0 以上。
  - 和上游比：
    - 上游 (a) 带历史时 RS − S 是 +5.8（+2.2 到 +9.4，按题算；精确 McNemar p = 0.002，未校正；705 题）。下游带历史后是 +0.8（−2.2 到 +3.9），区间跨 0，连方向也定不了。
    - 上游的"带减不带"是 +7.9（+3.3 到 +12.5，按题重抽），下游是 +2.3（−1.0 到 +5.7）。
    - 上游的区间按题算，下游按整场景重抽（同一场景的实例相关，区间更宽），两边区间的宽窄不能直接比。
    - 两边成功率水平不同（上游 S 约 40%，下游约 18%），百分点不能直接比大小（推断）。
- **训练过的模型对底座的差，六组都变大：**
  - 带历史时是 +15.4 到 +18.0 个百分点，不带时是 +9.0 到 +13.5。"带减不带"是 +3.7 到 +8.5，六组的区间都在 0 以上。

  - RD − B 的"带减不带"是 +3.7（+0.7 到 +6.6），未校正 p = 0.019，Holm 后 0.13。带、不带两版的差都在 0 以上，位置没变，按规则不算改变。
- **两种 RL 奖励之间：**
  - RD − RS：不带历史时 +4.0（+1.2 到 +6.7），带历史时 0.0（−2.7 到 +2.7）。
