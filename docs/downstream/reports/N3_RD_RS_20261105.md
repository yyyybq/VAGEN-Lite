# N3 各档两种 RL 直接比：RD − RS、Q3RD − Q3RS（2026-11-05）

> 依据：你 11-05 任务书第 5 条，原文是："N3 各档加 RD − RS、Q3RD − Q3RS 的配对比较（按题或按实例），写进 N3 报告和素材清单。"

## 结论

1. **Qwen2.5：密集 RL 在除 (a) 带历史以外的每一档都比稀疏 RL 高，+3.9 到 +6.5 个百分点。**
   - (a) 带历史时两者打平（−0.7，p = 0.74）。
   - 那是因为 RS 的优势只在带历史时才有：同样 705 题，带历史减不带历史，RD − RS 差 −5.4（−9.6 到 −1.3）。见第 3 条报告。
2. **Qwen3：Q3RD − Q3RS 在哪一档都不显著**，从 −2.7 到 +3.3。
3. **各档并排（差，括号里是精确 McNemar p，未校正；(a) 按题配对，其余按实例配对）：**

   | 档 | RD − RS | Q3RD − Q3RS |
   | --- | --- | --- |
   | (a) 上游原样，带历史（705 题） | −0.7（−4.1 到 +2.7；p = 0.74） | +3.3（−0.3 到 +6.9；p = 0.090） |
   | (a) 上游原样，不带历史（705 题） | +4.7（+1.5 到 +7.9；p = 0.0053） | +2.3（−0.8 到 +5.4；p = 0.18） |
   | (c) RoboCasa + 上游身体（585 个） | +6.5（+3.4 到 +9.6；p = 5.1×10⁻⁵） | +2.2（−0.7 到 +5.1；p = 0.17） |
   | (f) N1 的身体，转身不算碰撞（585 个） | +4.4（+1.7 到 +7.2；p = 0.0022） | +1.4（−1.2 到 +4.0；p = 0.37） |
   | (d) N1 原样，只取 (c) 的实例（585 个） | +3.9（+1.2 到 +6.7；p = 0.0076） | −0.5（−3.0 到 +1.9；p = 0.78） |
   | (d) N1 原样（600 个） | +4.0（+1.2 到 +6.8；p = 0.0063） | −0.5（−2.9 到 +1.9；p = 0.78） |
   | (e) 机器人自己的相机（300 个） | +4.7（+0.8 到 +8.6；p = 0.029） | −2.7（−5.9 到 +0.5；p = 0.15） |

   - 剔除版（N3 剔 1 个实例）的数字和上表差 0.1 个百分点以内，没有一处显著与否改变。
4. **跨档：**
   - RD − RS 在 (c) 减 (d) 上是 +2.6（−0.3 到 +5.5，同一批 585 个实例），比 RL 减 SFT 的 +3.6 小，区间含 0；
   - 在 (f) 减 (d) 上是 +0.5（−1.7 到 +2.7）。
   - 也就是说，转身被挡对 RD 和 RS 的伤害差不多。RD 比 RS 多出的 4 个百分点左右，从 (c) 到 (d) 基本保留下来。
5. **按宽松成功**（EVAL_PROTOCOL 第 6 节，只作参考）**方向一样，差得更大：**
   - RD − RS：(d) +5.2（p = 0.00075），(c) +8.0，(f) +5.6，(e) +5.7；
   - Q3RD − Q3RS 仍都不显著。

## 限定

- 每个模型一个检查点，评一遍；7 档 × 2 个比较都没有校正。各档的实例有重叠（(d) 两版、(c)/(f)/(d) 同一批实例），不是独立的 7 次检验。
- Qwen2.5 的 RS、RD 是同一轮（第 11 轮修正包）两次独立训练，起点同一个 SFT。Qwen3 的两个也是同起点。
