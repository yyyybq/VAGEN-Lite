> 发出前做了三轮独立核对，这一版已按核对意见改过：补了 Qwen3 的跨档差、两个检查点不在同一步、(a) 档的验证集参与过挑检查点。

## 结论

1. **Qwen2.5：密集 RL 在除 (a) 带历史以外的每一档都比稀疏 RL 高，+3.9 到 +6.5 个百分点。**
   - (a) 带历史时两者打平（−0.7，p = 0.74）。那是因为 RS 的优势只在带历史时才有，见第 3 条报告（[N3_NOHIST_20261105](N3_NOHIST_20261105.md)）。
   - 同样 705 题，带历史减不带历史，RD − RS 差 −5.4（−9.6 到 −1.3）。数据来源是 N3 新表 `report_20261105` 的跨档表，按题重抽 2,000 次。
2. **Qwen3：Q3RD − Q3RS 每一档本身都不显著，从 −2.7 到 +3.3。但同一批实例上的跨档差有一处区间不含 0（第 4 条）；不同题之间，(a) 带历史对 (e) 的独立样本 z 检验 p = 0.016（+3.3 对 −2.7，未校正），(a) 对 (d) p = 0.088。**
3. **各档并排**（差；括号里是 95% 区间（配对，正态近似）和精确 McNemar p，未校正；(a) 按题配对，其余按实例配对）：

   | 档 | RD − RS | Q3RD − Q3RS |
   | --- | --- | --- |
   | (a) 上游原样，带历史（705 题） | −0.7（−4.1 到 +2.7；p = 0.74） | +3.3（−0.3 到 +6.9；p = 0.090） |
   | (a) 上游原样，不带历史（705 题） | +4.7（+1.5 到 +7.9；p = 0.0053） | +2.3（−0.8 到 +5.4；p = 0.18） |
   | (c) RoboCasa + 上游身体（585 个） | +6.5（+3.4 到 +9.6；p = 5.1×10⁻⁵） | +2.2（−0.7 到 +5.1；p = 0.17） |
   | (f) N1 的身体，转身不算碰撞（585 个） | +4.4（+1.7 到 +7.2；p = 0.0022） | +1.4（−1.2 到 +4.0；p = 0.37） |
   | (d) N1 原样，只取 (c) 的实例（585 个） | +3.9（+1.2 到 +6.7；p = 0.0076） | −0.5（−3.0 到 +1.9；p = 0.78） |
   | (d) N1 原样（600 个） | +4.0（+1.2 到 +6.8；p = 0.0063） | −0.5（−2.9 到 +1.9；p = 0.78） |
   | (e) 机器人自己的相机（300 个） | +4.7（+0.8 到 +8.6；p = 0.029） | −2.7（−5.9 到 +0.5；p = 0.15） |

   - 剔除版（N3 剔 1 个实例）：表内各数差 0.1 个百分点以内；第 4 条的跨档区间端点差 0.2 以内，宽松成功的 Q3RD − Q3RS (c) 减 (d) 除外（+1.9，−1.0 到 +4.8 → +1.7，−1.0 到 +4.5）；第 5 条宽松成功的 (c) Q3RD − Q3RS 从 +0.9 变成 +0.7；没有一处显著与否改变。
4. **跨档（同一批 585 个实例上，两档的差值之差，按实例重抽）：**
   - Qwen2.5 的 RD − RS：
     - 从 (c) 的 +6.5 降到 (d) 的 +3.9，降 2.6（−0.3 到 +5.5，区间含 0）。按宽松成功，同一个差是 +3.1（+0.2 到 +6.2），不含 0。
     - 点估计：降的 2.6 里，平移那一步（(c) 减 (f)）+2.1（+0.0 到 +4.1），转身那一步（(f) 减 (d)）+0.5（−1.7 到 +2.7）；两步之差 +1.5（−1.7 到 +4.8），分不开。
     - 和 (f) 档报告（[N3_TIER_F_20261105](N3_TIER_F_20261105.md)）一样：这只是先平移、后转身一种拆法，转身后压进台面造成的平移被挡也算在 (c) 减 (f) 里，拆分定不下来。
     - 这个降幅比 RD − S 在 (c) 减 (d) 上的 +3.6（+0.7 到 +6.2）小。
     - (d) 里 RD 仍比 RS 高约 4 个百分点。
   - Qwen3 不一样：Q3RD − Q3RS 在 (c) 减 (d) 上是 +2.7（+0.2 到 +5.3），(f) 减 (d) 是 +1.9（+0.0 到 +3.8）。
     - 也就是说，机器人身体对 Q3RD 的伤害比对 Q3RS 大。点估计多半在转身那一步（+1.9，平移那一步 +0.9），但拆分同样定不下来：转身那部分占的比例，按实例重抽是 −14% 到 211%。
     - 这和转身多少一致：在 (d) 里，Q3RD 的动作约 39% 是转身，Q3RS 约 23%。
     - 按宽松成功，这个差是 +1.9（−1.0 到 +4.8），含 0。
5. **按宽松成功**（EVAL_PROTOCOL 第 6 节，只作参考）：
   - RD − RS 方向一样，差得更大：
     - (d) 600 个 +5.2（p = 0.00075）；只取 (c) 实例的 585 个 +5.0（p = 0.0013，从 `terminal_20261105/d.jsonl` 取 (c) 的实例算）；
     - (c) +8.0，(f) +5.6，(e) +5.7。
   - Q3RD − Q3RS 方向不变，多数变小：(c) +0.9，(f) +0.3，(e) −2.3，(d) −1.0，都不显著。

## 限定

- 每个模型一个检查点，评一遍；每种 RL 一个训练种子；7 档 × 2 个比较都没有校正。
- 各档不是独立的检验：(a) 两版是同一批 705 题；(d) 两版、(c)/(f)/(d) 是同一批实例；(e) 的 300 个里 236 个和 (d) 同场景、同起点（实例名相同），其中 152 个目标和参数也一样（只换了相机），另 84 个换了目标或参数；这 236 个里 226 个也在 (c)/(f) 里。
- 两个检查点不在同一步，Qwen3 的两次训练也不只差奖励：
  - Qwen2.5：RS 是 P-S0 第 300 次，RD 是 P-D 第 150 次，各自按主线验证集挑的；两次训练只差奖励设置，起点同一个 SFT（第 9 个 epoch），同种子 20260930。
  - Qwen3：Q3RS 是 S0 第 100 次（这一臂第 150 次因读不出的回答超过 10% 被停），Q3RD 是 V4 第 300 次，起点同一个 SFT，同种子 20261019。V4 除了奖励，还换了更新时的分组过滤：V4 先和 S0 一样留有成有败的组（不够再补抽），空着的位置再用全败、但回报离散度 ≥ 0.3318 的组补上（离散度不到 1.0 的组，优势按比例缩小）；S0 不补全败的组。所以 Q3RD − Q3RS 不只是奖励之差。
- (a) 档不是完全留出的：
  - 它的验证集 413 题里，包括挑检查点用的题。Qwen2.5 按 val400 挑，这 398 题都在 413 题里；Qwen3 的训练链直接按 v2 验证集挑。
  - 只看测试集 292 题：带历史仍分不开（+1.4，34 对 30，p = 0.71；全部 705 题是 −0.7），不带历史 +6.2，带历史减不带历史 −4.8（−11.3 到 +1.7，区间含 0）；后两个和全部 705 题方向一样，但这个差只看测试集不显著。
- 两个 RL 的差，没有跟"同一配置换种子"的差比过（未核实）。
