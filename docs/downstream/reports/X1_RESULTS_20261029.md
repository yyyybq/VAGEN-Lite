# X1 冻结主干：结果（2026-10-29）

> 依据：你 10-26 的决定（设计见 [X_DESIGNS_20261026.md](X_DESIGNS_20261026.md) 的 X1 一节）。四个起点都训完了，都评了 944 回合。

## 结论

1. **只训动作头基本学不会这些任务。**
   - 视觉语言模型整个冻结（视觉塔、合并层、语言模型、`lm_head`），只训动作头。30% 示教，5 万步。
   - 四个起点的总体成功率都在 2% 以下：B 0.1%（1/944）、S 1.3%（12）、RS 1.4%（13）、RD 1.7%（16）。
   - 作参照：全量微调训到第 5 万步（100% 示教，E0）是 10.6%–18.0%。两边示教比例不同，只作参照。
2. **能学会的只有几个简单的大动作任务，而且只有主线的三个起点学会了。**
   - S、RS、RD 的成功几乎都在 SlideDishwasherRack（7–10 次）和 CloseFridge（各 3 次）上，零星有 OpenStandMixerHead 和 TurnOnSinkFaucet。
   - B 只成功了 1 次（NavigateKitchen）。
3. **差异不显著，证据很弱。**
   - 和 B 逐任务比，三个起点按任务平均都只高 0.9–1.3 个百分点，Wilcoxon p = 0.125–0.5。只有 2–4 个任务有差别，检验几乎没有效力。
   - 这一点只能当作"冻结后主线起点的表征对动作稍微有用一点"的弱线索。在这么低的成功率上，起点之间的差看不清。
4. 结合 X4（E1 全量微调后语言能力全崩）来看：下游要学会这些任务，必须改动视觉语言模型本身；但全量改又会毁掉原来的能力。T2（LoRA）正好介于两者之间，它的 B、RS 已排队。

## 做法

- **配方**：StarVLA 的 `freeze_modules` 冻结整个 `qwen_vl_interface`，只训动作头（1.29 亿参数）。
- **训练**：30% 示教（7,500 条），5 万步，学习率按 5 万步余弦衰减，其余同 E1。
- **成本**：每步约 0.32 秒（全量微调 0.66–0.75 秒），显存峰值 25.4 GB。训练任务内评第 5 万步，944 回合。
- **统计**：同 E1，逐任务配对（34 个任务），只用两边都完成的回合。
- **卡时**：每个约 4.5 小时训练 + 3.8 小时评测，8 卡；四个约 270 卡时（未核实）。
