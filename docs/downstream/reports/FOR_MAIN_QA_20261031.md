## 1. 两代模型经主线 SFT 后，单图上的静态空间判断都下降

| 题集（510 道） | B → S / RS / RD | Q3B → Q3S / Q3RS / Q3RD |
| --- | --- | --- |
| X0：RoboCasa 厨房画面 | 66.3% → 57.3% / 56.1% / 53.9% | 75.7% → 62.5% / 64.1% / 67.8% |
| X0b-1：InteriorGS 画面（主线题库的验证、测试场景） | 80.2% → 69.0% / 66.1% / 65.1% | 85.9% → 72.4% / 70.0% / 74.7% |

- 六个训练过的模型在两套题上都显著低于本家底座：X0 上 p ≤ 0.0016，X0b-1 上 p ≤ 2.1×10⁻⁶。
- 换成主线自己的 InteriorGS 画面，照样下降；换成主线自己的带标签问法（X0b-2），训练过的模型也没有更好。所以不是画面或问法的差别。
- 掉得最多的是"以机器人朝向为前，哪个更靠前"：Qwen2.5 在两套题上、Qwen3 在 X0b-1 上，都掉到随机水平附近。Qwen3 的左右判断也掉了 15–23 个百分点。原因没查（未核实）。
- 主要损失在 SFT 这一步，RL 在 SFT 之上改变不大：
  - Qwen2.5 的密集奖励 RL 在 SFT 之上又低约 3–4 个百分点（p < 0.01）；
  - Qwen3 的 V4 在 X0 上比 SFT 高 5.3 个百分点（p = 0.0024），但仍比 Q3B 低 7.8。
- 线性探针（读完题后的隐藏状态）读出的空间信息也少了：3/4 深度那一层，B 73.9% → 66.7%–68.6%，Q3B 71.6% → 62.5%–67.5%。

## 2. Qwen3 的通用识别也下降，Qwen2.5 的没有显著下降

G0 是 300 道不考空间的识别题（存在、辨认、开合、数量），用 X0 的厨房画面：

| | 底座 | SFT | RS | RD |
| --- | ---: | ---: | ---: | ---: |
| Qwen2.5 | 80.0% | 78.7%（p 0.64） | 77.3%（p 0.30） | 76.0%（p 0.088） |
| Qwen3 | 86.7% | 77.7%（p 9.9×10⁻⁵） | 75.3%（p 5.4×10⁻⁶） | 78.3%（p 4.7×10⁻⁴） |

- Qwen3 四类题都掉，数量题掉得最多：72.5% → 52.5% / 45.0% / 55.0%，只有 40 道。
- 这不是格式问题：训练过的 Qwen3 常写成 "A. open"，但字母照样读得出，解析不出的不超过 0.3%。

## 3. 参数距离的三组数字

相对距离 = ‖A − B‖ / ‖B‖，全部参数拼在一起算。

| 组 | 差 | 全部参数 | 视觉塔 |
| --- | --- | ---: | ---: |
| ① Qwen2.5 主线训练 | S − B | 0.0093 | 0（SFT 没动视觉塔） |
| | RS − S / RD − S | 0.0011 / 0.0009 | 0.0013 / 0.0010 |
| ② Qwen3 主线训练 | Q3S − Q3B | 0.0076 | 0 |
| | Q3RS − Q3S / Q3RD − Q3S | 0.0006 / 0.0009 | 0.0003 / 0.0005 |
| ③ 下游 E1（StarVLA 在 RoboCasa 100% 数据上 20 万步） | E1 后 − E1 前，四个起点 | 0.0757–0.0763 | 0.1018–0.1019 |

- **① ②：** 主线训练的改动约九成来自 SFT，RL 只占约十分之一。两种 RL 的改动方向几乎正交：RS − S 和 RD − S 的余弦，Qwen2.5 是 0.077，Qwen3 是 0.071。
- **③：** 下游训练对每个起点的改动约是主线 SFT 的 8 倍，四个起点逐层的改动大小几乎一样。
