# X2 极低数据：结果（2026-10-29）

> 依据：你 10-26 的决定（设计见 [X_DESIGNS_20261026.md](X_DESIGNS_20261026.md) 的 X2 一节），以及 10-28 任务书里"X2 1% + 3% 报完即可"。8 个训练都完成了，每个都在 944 回合上评过。

## 结论

1. **数据极少时，起点之间的差没有变大。**
   - 1%（每任务 5 条示教）：四个起点总体成功率都在 4.5%–5.4%。和 B 逐任务比，差在 −0.2 到 +1.5 个百分点之间，都不显著（p ≥ 0.22）。
   - 3%（每任务 15 条）：总体 11.0%–13.8%。RS 比 B 高 3.4 个百分点（95% 区间 0.0 到 +7.5，p = 0.11），S、RD 和 B 差不多。
2. **RS 在每一档数据量上都比 B 略高，但几乎都不显著。**
   - 按任务平均，1% / 3% / 10% / 30% / 100% 依次是 +1.5 / +3.4 / +3.7 / +2.0 / +1.5 个百分点。
   - 只有 10% 这一档 p < 0.05（p = 0.037）。这里没做多重比较校正，三个起点 × 五档共 15 个比较，校正后不显著。
   - RD 也只在 10% 这一档 p < 0.05（+4.3，p = 0.035）。S 每一档都和 B 没有差别。
3. **空间组（9 个任务）上没有好处。** 没有哪个起点在哪一档显著好于 B。RS 在 1% 和 3% 的点估计还是负的（−2.2、−0.4）。也就是说，主线的空间训练在低数据下也没有让下游的空间任务变好。
4. **多步任务在极低数据下基本学不会**：1% 时 0–1 / 434，3% 时 2%–3%。

## 读的时候注意

- **两种步数混在一条曲线上。** 10%、30%、100% 是 E2、E1 的最终检查点，固定训 20 万步，不是 2 个 epoch。所以这条曲线混了数据量和步数两个因素，只作对照。
- **100% 一行和 E1 报告的主数字不同。** 这里 100% 只取第 20 万步。E1 报告的主数字是三点平均（第 15 万、17.5 万、20 万步），那里 RS − B 是 +2.9（p = 0.008）。两种取法差这么多，说明单个检查点上的差要按 E0 量出的起伏来读：相邻检查点之间平均差约 3 个百分点。
- **100% 第 20 万步的成功率低于 30%**，四个起点都是这样。E2 报告讨论过，可能是 100% 那档训练不足（20 万步只够看 0.36 个 epoch，未核实）。

## 做法

- **数据**：每个任务取 RoboCasa 官方打乱顺序的前 5 条（1%）和前 15 条（3%）示教，和 10%、30% 子集是同一个排列，所以 1% ⊂ 3% ⊂ 10%。
- **训练**：固定 2 个 epoch，1% 是 10,368 步、3% 是 32,080 步；学习率按各自的总步数余弦衰减，其余同 E1。训练任务自己评最终检查点，944 回合。
- **统计**：逐任务配对，34 个任务为配对单位，同 E1。报按任务平均的差、bootstrap 95% 区间和 Wilcoxon 符号秩检验，只用两边都完成的回合。
- **卡时**（按任务时长估，未核实）：
  - 1% 每个约 2.3 小时训练 + 3.8 小时评测；3% 每个约 6.8 小时训练 + 3.8 小时评测；都是 8 卡。
  - 8 个合计约 540 卡时，不算 10-27 为了腾机器停下又重来的部分。
- **文件**：结果在 `downstream_runs/x/X2/results/`（`results.json`、`results.md`），代码 `downstream/x/x2_analyze.py`（测试 `test_x2_analyze.py`）。
