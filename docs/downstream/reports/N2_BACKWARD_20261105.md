# N2 的"先后退"偏向：按最短走法第一步分两组（2026-11-05）

> 依据：你 11-05 任务书第 8 条，原文是："先后退偏向只做分析：N2 三档按实例最短走法第一步是不是 move_backward 分两组，重算'训练过的起点减底座'和'RL 减 SFT'；另报每个模型每档第一步最优的比例。不重训。"

## 结论

1. **N1 合并 600 个实例里，451 个（75%）最短走法第一步是后退。原因是机器人一开始几乎都贴着台面。**
   - 另外 149 个的第一步：左移 55，右移 39，左转 38，右转 11，前进 6。
   - 第 7 条算单步真值时顺便看到，从起点各走一步，被 N1 的机器人身体挡住的次数（600 个实例里）：前进 575，左转 336，右转 344，右移 184，左移 101，后退 20。
2. **两个底座加示教后，几乎每个回合第一步都后退，第一步不该后退的 149 个实例上全做不成。底座的跳升全部来自第一步该后退的那 451 个实例。**
   - 底座第一步后退的比例（第一步后退的部分 / 其余部分）：
     - B：0 条 0% / 0%，100 条 99% / 99%，300 条 100% / 100%，1,000 条 100% / 94%；
     - Q3B：0 条 11% / 13%，100 条 100% / 100%，300 条 100% / 99%，1,000 条 98% / 91%。
   - 底座的成功数：

     | 底座 | 部分 | 0 条 | 100 条 | 300 条 | 1,000 条 |
     | --- | --- | ---: | ---: | ---: | ---: |
     | B | 第一步后退（451 个） | 0 | 94 | 93 | 93 |
     | B | 其余（149 个） | 6 | 0 | 0 | 0 |
     | Q3B | 第一步后退（451 个） | 24 | 93 | 96 | 95 |
     | Q3B | 其余（149 个） | 4 | 0 | 2 | 3 |

   - N2 报告里写过"底座那一跳多半是学到了这条规律（未单独核实）"。现在核实了：是。
3. **"训练过的减底座"：0 条时的优势全在第一步该后退的那部分；100 条以后底座在这部分追平，训练过的只在其余那部分领先。**
   - 0 条：
     - 第一步后退的部分：S +15.5，RS +12.6，RD +17.5，Q3S +11.8，Q3RS +12.2，Q3RD +11.3；
     - 其余部分：S −2.7，RS 0.0，RD +1.3，Q3S +1.3，Q3RS +1.3，Q3RD +2.0；
     - 两部分之差 p 都 ≤ 0.001。
   - 100 条：
     - 第一步后退的部分：−4.0 到 +1.8（RS −4.0，p = 0.039）；
     - 其余部分：+1.3 到 +5.4（底座在这部分是 0）；
     - 两部分之差：S −4.5（p = 0.050），RS −9.4（p = 0.0003），RD −4.7（p = 0.047）。未校正。剔除版里 S、RD 这两处是 0.074、0.070。
   - 1,000 条：
     - Qwen2.5 三个：第一步后退的部分领先 +4.0 到 +6.7（p ≤ 0.0014）；其余部分 +2.7 到 +4.7，只有 RS 的 p < 0.05（0.016）；
     - Qwen3 三个在两部分都不显著。
4. **RL 减 SFT：分两组以后，也基本分不开。**
   - 只有两处 p < 0.05（未校正）：
     - RS − S：0 条和 100 条时，在第一步后退的部分 −2.9（p = 0.085、0.073），在其余部分 +2.7、+2.0。两部分之差 −5.6（p = 0.013）、−4.9（p = 0.034）。
     - Q3RD − Q3S：300 条时第一步后退的部分 −2.7（p = 0.023），全部 600 个上 −2.5（p = 0.0081）。
   - 其余 RL 减 SFT，在两部分、各档都不显著。
   - 2 部分 × 4 档 × 4 对，共 32 个检验没校正，这两处只算线索。
5. **第一步最优的比例。** 第一步最优 = 第一个执行的动作就是记录的那条最短走法的第一步。这是下限：别的同样短的走法可能换个动作开头。
   - 0 条：
     - 训练过的六个，第一步后退的比例在两部分差不多：S 39% / 34%，RS 19% / 17%，RD 36% / 35%，Q3S 40% / 38%，Q3RS 42% / 38%，Q3RD 43% / 44%。也就是说，主线训练后，除了 RS（约两成），约三分之一到四成多的回合先后退，但不看实例该不该退；
     - 其余部分第一步最优：S 28%，RS 23%，RD 19%，Q3S 27%，Q3RS 23%，Q3RD 21%；B 17%，Q3B 3%。
   - 加示教后：
     - 第一步后退的部分，第一步最优（就是后退）：100 条 57%–100%，300 条 88%–100%，1,000 条 94%–100%；
     - 其余部分，第一步最优反而降：100 条 0%–15%，300 条 0%–9%，1,000 条 3%–16%；这一部分第一步就后退的，100 条 51%–100%，300 条 81%–100%，1,000 条 74%–94%。
   - 每个模型每档的全表在 `report.md` 的"第一步"一节。

## 怎么做的

- 分组：按实例记录的最短走法（`shortest.path`，`n_gen.py` 生成实例时搜到的第一条最短成功走法）的第一个动作。
- 回合：0 条用 N1 合并 600（重跑后的），100、300、1,000 条用 N2 的回合（`N2/<模型>/eval/<条数>/`）。第一个动作是回合里第一个真正执行的动作。
- 统计：和 N2 报告一样，逐实例配对精确 McNemar；两部分之差用独立样本 z 检验（`n_report.agree`），把两部分当独立的。
- 代码：`downstream/n/n2_backward.py`（`c5cfff93`），单元测试在 `test_n_terminal.py`。只在登录节点上算，不占卡。
- 剔除版（剔 N2 自己的 7 个坏画面实例，593 个：446 / 147）结论一样，只有第 3 条里注明的两处 p 跨过 0.05。

## 限定

- "第一步最优"是下限，只认记录的那一条最短走法。
- 两部分实例数差很多（451 对 149），其余部分的成功数很小（0–8 个），差值的区间宽。
- N2 每档只有一个训练种子；检验没有校正。
