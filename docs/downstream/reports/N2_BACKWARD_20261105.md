# N2 的"先后退"偏向：按最短走法第一步分两组（2026-11-05）

> 依据：你 11-05 任务书第 8 条，原文是："先后退偏向只做分析：N2 三档按实例最短走法第一步是不是 move_backward 分两组，重算'训练过的起点减底座'和'RL 减 SFT'；另报每个模型每档第一步最优的比例。不重训。"
>
> 发出前做了三轮独立核对，这一版已按核对意见改过：Q3B 在其余部分不是全做不成；剔除版跨过 0.05 的有四处；分组本身受生成器搜索顺序影响。

## 结论

1. **N1 合并 600 个实例里，451 个（75%）记录的最短走法第一步是后退。主要因为机器人一开始几乎都贴着东西，加上生成器搜索时先试前进、后退。**
   - 另外 149 个的第一步：左移 55，右移 39，左转 38，右转 11，前进 6。
   - 第 7 条算单步真值时顺便看到，从起点各走一步，被 N1 的机器人身体挡住的次数（600 个实例里）：前进 575，左转 336，右转 344，右移 184，左移 101，后退 20。挡住前进的多是柜子（228）、水槽（138）、抽屉（66）、灶台（62）。
   - 记录的那条最短走法，是生成器按"前进、后退、左移、右移、左转、右转"的顺序广度优先搜到的第一条。前进多半被挡，所以几条一样短的走法里，留下的总是先后退的那条。
     - 所以这 451 个的意思是：在至少 2 个动作的走法里，后退是最短的第一步之一，不一定是唯一的。不限动作数时，下面列的前两个实例左转一步就能做成，后退就不是最短的了。
     - 例子：OpenDrawer_s1004 的左右关系实例，记录的是 [后退, 左转, 左转]；RS（0 条）、RD（0、100 条）、S（100、300 条）的回合是左转三次，也 3 步做成。
   - 生成器只认至少 2 个动作的走法。有 3 个实例，回合里 1 个动作就做成了，而记录的第一步一步做不成：
     - OpenDrawer_s1004 的画面占比实例：左转一步就成，记录的是 [后退, 左移]；
     - PickPlaceToasterToCounter_s1001 的左右关系实例：左转一步就成，记录的是 [后退, 后退]；
     - StoreLeftoversInBowl_s3002 的同框实例：右转一步就成，记录的是 [左移, 右转]。
     - 前两个在"第一步后退"那一组里。这 3 个实例上，记录的第一步不是最优的。
2. **两个底座加示教后，几乎每个回合第一步都后退；在第一步不该后退的 149 个实例上，B 全做不成，Q3B 只成 0–3 个。底座的跳升全部来自第一步该后退的那 451 个实例。**
   - 底座第一步后退的比例（第一步后退的部分 / 其余部分）：
     - B：0 条 0% / 0%，100 条 99% / 99%，300 条 100% / 100%，1,000 条 100% / 94%；
     - Q3B：0 条 11% / 13%，100 条 100% / 100%，300 条 100% / 99%，1,000 条 98% / 91%。
   - 底座的成功数：

     | 底座 | 部分 | 0 条 | 100 条 | 300 条 | 1,000 条 |
     | --- | --- | ---: | ---: | ---: | ---: |
     | B | 第一步后退（451 个） | 0 | 94 | 93 | 93 |
     | B | 其余（149 个） | 6 | 0 | 0 | 0 |
     | Q3B | 第一步后退（451 个） | 24 | 93 | 96 | 95 |
     | Q3B | 其余（149 个） | 4 | 0 | 2 | 3 |

   - N2 报告第 6 条写过："所以底座那一跳里，很大一部分可能就是学到'先后退'这条简单规律（未单独核实）"。现在核实了：是。
   - 顺带更正 N2 报告同一节的一个数：B 在 1,000 条时，第一步就是后退的是 600 个回合里的 590 个，不是 584 个（Q3B 580、S 542 没错）。
3. **"训练过的减底座"：0 条时的优势全在第一步该后退的那部分；到 100 条，底座在这部分追平，训练过的在其余部分领先；300、1,000 条时，Qwen2.5 又在第一步后退的部分领先，Qwen3 两部分都不显著。**
   - 0 条：
     - 第一步后退的部分：S +15.5，RS +12.6，RD +17.5，Q3S +11.8，Q3RS +12.2，Q3RD +11.3；
     - 其余部分：S −2.7，RS 0.0，RD +1.3，Q3S +1.3，Q3RS +1.3，Q3RD +2.0；
     - 两部分之差 p 都 ≤ 0.001（剔除版 ≤ 0.002）。
   - 100 条：
     - 第一步后退的部分：−4.0 到 +1.8（RS −4.0，p = 0.038）；
     - 其余部分：+1.3 到 +5.4（底座在这部分是 0），RS、RD、Q3RD 的 p < 0.05（0.0078、0.031、0.0078）；
     - 两部分之差：S −4.5（p = 0.0497），RS −9.4（p = 0.0003），RD −4.7（p = 0.047）。都未校正。
   - 300 条：第一步后退的部分 RS +3.8（p = 0.030）、RD +3.8（p = 0.021）；其余部分都不显著。
   - 1,000 条：
     - Qwen2.5 三个：第一步后退的部分领先 +4.0 到 +6.7（p ≤ 0.0015）；其余部分 +2.7 到 +4.7，只有 RS 的 p < 0.05（0.016）；
     - RD 的两部分之差 +4.0（p = 0.042，未校正），方向和 100 条时相反；
     - Qwen3 三个在两部分都不显著。
4. **RL 减 SFT：分两组以后，也基本分不开。**
   - 两对比较里，有 3 个检验 p < 0.05（都未校正）：
     - RS − S 的两部分之差：0 条 −5.6（p = 0.013），100 条 −4.9（p = 0.034）。这两处是 RS 在第一步后退的部分低（−2.9，p = 0.085、0.072），在其余部分高（+2.7、+2.0）。
     - Q3RD − Q3S：300 条时第一步后退的部分 −2.7（p = 0.023）。
   - 这 3 个出自 48 个检验：32 个分部分的，加 16 个两部分之差。只算线索。
   - 全部 600 个上，Q3RD − Q3S 在 100 条是 +2.7（p = 0.033），在 300 条是 −2.5（p = 0.0081），方向相反，N2 报告里报过。
5. **第一步最优的比例。** 第一步最优 = 第一个动作就是记录的那条最短走法的第一步。
   - 这大体是下限：别的一样短的走法可能换个动作开头。例外是第 1 条说的 3 个实例，那里记录的第一步本身不是最优。
   - "第一个动作"是回合里第一个读得出的回复里的第一个动作，被挡住的也算。按回合记录，0 条时 B 有 314 个回合、Q3B 有 505 个回合的第一个动作被挡住。
   - 0 条：
     - 训练过的六个，第一步后退的比例在两部分差不多：S 39% / 34%，RS 19% / 17%，RD 36% / 35%，Q3S 40% / 38%，Q3RS 42% / 38%，Q3RD 43% / 44%。也就是说，主线训练后，除了 RS（约两成），约三分之一到四成多的回合先后退，但不看实例该不该退；
     - 其余部分第一步最优：S 28%，RS 23%，RD 19%，Q3S 27%，Q3RS 23%，Q3RD 21%；B 17%，Q3B 3%。
   - 加示教后：
     - 第一步后退的部分，第一步最优（就是后退）：100 条 57%–100%，300 条 88%–100%，1,000 条 94%–100%；
     - 其余部分，第一步最优反而降：100 条 0%–15%，300 条 0%–9%，1,000 条 3%–16%。例外是 Q3B 1,000 条（0 条 3% → 5%）；
     - 其余部分第一步就后退的：100 条 51%–100%，300 条 81%–100%，1,000 条 74%–94%。
   - 每个模型每档的全表在 `report.md` 的"第一步"一节。

## 怎么做的

- 分组：按实例记录的最短走法（`shortest.path`）的第一个动作。记录的是 `n_gen.py` 生成实例时搜到的、至少 2 个动作的第一条成功走法。
- 回合：0 条用 N1 合并 600（重跑后的），100、300、1,000 条用 N2 的回合（`N2/<模型>/eval/<条数>/`）。
- 统计：和 N2 报告一样，逐实例配对精确 McNemar；两部分之差用独立样本 z 检验（`n_report.agree`），把两部分当独立的。
- 代码：`downstream/n/n2_backward.py`（`c5cfff93`；`2fb229d3` 只改了 report.md 里"第一步"一节的定义文字，表里的数不变），单元测试在 `test_n_terminal.py`。只在登录节点上算，不占卡。
- 剔除版（剔 N2 自己的 7 个坏画面实例，593 个：446 / 147）结论一样，有四处 p 跨过 0.05：
  - S − B 两部分之差，100 条：0.0497 → 0.074；
  - RD − B 两部分之差，100 条：0.047 → 0.070；
  - RS − B 第一步后退的部分，100 条：−4.0（p = 0.038）→ −3.6（p = 0.064）。剔除版里，100 条时没有一个训练过的模型在这部分和底座分得开；
  - S − B 全部实例，300 条：+2.3（p = 0.065）→ +2.5（p = 0.044）。

## 限定

- 分组受生成器搜索顺序影响（第 1 条）："第一步后退"的意思是，在至少 2 个动作的走法里，后退是最短的第一步之一；不限动作数时，第 1 条那 2 个实例左转一步就能做成，那里后退不是最短的。
- "第一步最优"大体是下限，只认记录的那一条最短走法；有 3 个实例例外（第 1 条）。
- 两部分实例数差很多（451 对 149），其余部分的成功数很小（0–8 个），差值的区间宽。
- N2 每档只有一个训练种子；检验没有校正。
