# 第一波诊断汇总：主线起点相对原始 7B 的方向表（2026-10-29）

> 依据：你 10-28 任务书第 0 节要的"第一波诊断汇总报告（含所有设定下 RS−B / RD−B / S−B 的方向表）"。那条更早的提示词没到这个窗口，这份按名字理解来写；你重发原提示后，我按原提示补。表里是到 10-29 为止所有做完的设定。X0b、G0、线性探针、参数距离的设计还在等你确认，所以没有这几行。

## 结论

1. **主线的空间训练没有让 Qwen2.5-VL-7B 在 RoboCasa 上更会做事。**
   - S、RD 在任何一个下游成功率设定上都没有稳定的方向。
   - 显著的只有 RD 在 E2 10% 上 +4.3（p = 0.035，没做多重比较校正）。
2. **RS 有一个小而方向一致的优势，只在部分设定上显著。**
   - 9 个下游成功率设定里，RS − B 有 7 个为正：+1.1 到 +3.7 个百分点。
   - 单独显著的只有 E1（三点平均 +2.9，p = 0.008）和 E2 10%（+3.7，p = 0.037）。
   - 未见任务（X5）和导航单任务（T5）上是负的。
   - 训练种子只有一个（T1 种子 2 推迟了），这个优势是否超出种子噪声，还没法判断。
3. **和空间直接相关的诊断，三个主线起点都不比 B 好。**
   - 在厨房画面上答空间问题（X0），三个都显著比 B 差 9–12 个百分点。
   - 选对要操作的目标（X3），S、RS 和 B 一样，RD 显著更差（−8.3）。
4. **只有一样是主线起点明显更好：语言能力被下游训练毁得少一些（X4）。** 但四个 E1 模型的文字回答都彻底崩了，这个差别没有实际用处。
5. **RL（E3）没有帮上任何起点。** S、RD 被 RL 拉低了约 3 个百分点，原因见 E3 报告。
6. **Qwen3 上（模型线的数字，我们没复核）也是同样的方向。** 模型线按 E1 协议跑了 Qwen3 下游：SFT、RS 和原始 Qwen3 差不多；RD 显著更差，总体 −3.2（p = 0.032），空间组 −4.9（p = 0.016）。

## 读的时候注意

- **设定之间不独立。** 同一个起点在每个设定里都出现，所以"RS 9 个里 7 个为正"不能当成 9 次独立的证据。
- **只有一个训练种子。** E0 量过：同一起点相邻检查点之间的差，平均约 3.3 个百分点，和起点之间的差一样大。E1 改用三点平均，就是为了平掉一部分这种起伏，但训练种子带来的差平不掉。T1（种子 2）原本就是为了量这个，10-28 推迟了。
- **E3 的 RL 训练几乎没拿到成功信号**（训练时成功率 0%–2%）。所以这一行反映的是"这套 RL 设置"，不是"RL 本身"。
- **X4 那一行是"损伤更小"，不代表能力保住了。** 四个 E1 模型在主线题上都是 0%。
