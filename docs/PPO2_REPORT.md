## 0. 结论

1. **第 1 关（特权 critic 试点 qw3tgfcd）门 A 不通过。**
   - `critic/all/values/explained_var_valid` 在第 76–90 步平均 **0.281**，在第 91–100 步平均 **0.334**。线是两段都 ≥ 0.3。
   - 比三次模型 critic 试点（全部候选上约 0.1 或更低）高很多，但只在门槛附近，前一段没到。
   - 按 PREREG_PPO2，第 2、3 关不交。
2. **第 0 关（表征探针）读法：弱。**
   - C0 SFT e8 在 critic 读值位置的隐状态，线性读剩余回报 G_t，折外 EV 最高 **0.193**（第 27 层）。

3. **两关合起来的读法（推断）：** 价值本身就难预测。
   - 即使用环境真值，离线 EV 也只有约 0.35，在线约 0.28–0.33。剩下的方差大概来自之后的采样（同一个状态，之后走得好不好）。
   - 模型的表征比真值还少一截，线性只有约 0.19。所以从 C0 起的价值网络 EV 在 0.1 左右，并不意外。
   - 在这个任务上，critic 能给逐轮 PPO 的方差缩减有限，这和第一段"逐轮 PPO 和 GRPO 持平"一致。
   - 这是和数据一致的解释，没有做消融。

## 3. 限度

- 第 1 关只有一个种子、一条 V4，100 步。门 A 的分段平均受单步波动影响大，第 76–90 段 0.281 离线只差 0.02。按 PREREG 不重跑。
- 第 0 关只看了起点 C0 SFT e8，没看 RL 之后的模型。
- 回答的 token 是按文本重新分词的，不是采样时的原始 id；Qwen 的分词几乎总是规范的，影响应很小。
- 探针的局用的是评测的单局循环，不是训练的 agent loop，所以采样方式和训练略有不同：温度 0.8、top-p 0.92，种子按回合固定。
- 两关合起来的解释（价值本身难预测）没有直接检验，比如没算"同一状态多次采样的回报方差"。
