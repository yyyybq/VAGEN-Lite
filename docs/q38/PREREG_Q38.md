## 4. 判定（照 8B；正式稿逐条抄原文）

- **通用规则**：同题配对符号检验。判两者有差别，要同时满足：p < 0.05、每个种子同号、差 ≥ 5 个点。
- **Q1**：
  - 每条 RL 运行对它的 SFT 起点（705 道和筛选集各算一次）。8B 的结果：10/10 更高。
  - V4 − S0 照通用规则判。8B：+0.88，p 0.29，判"没有差别"。
- **Q2（矩阵）**：照 PREREG_D_vs_C 的 H1 / H2 / H3。
  - H1：D − C 照通用规则判。8B：+4.54，没到 5 个点，不成立。
  - H2：探针的 goal_now / goal_after。
  - H3：卡在关系条件上的失败比例。
  - 探索性对照照 8B 再算一遍：相同更新次数下的比较、Cr − C、Cr − D。
- **Q5**：照 PREREG_P3_*。奖励变体要比同规则的稀疏臂平均高 ≥ 3 个点，而且每个种子都为正。
  - 对照：S-PPO1、S-PPO3、D-GRPO。
  - 读数：第 50、100 次的平均。
  - 发散之后的读数只报，不进判定。
- **读哪个检查点**：GRPO 读第 300 次，或者被停之前的最后一个检查点；被守卫停下的运行照 8B 的规矩报。
